Claude Code: Bash sandbox と Hooks

🛡️ Bash sandbox は任意設定

Claude Code の sandbox は承認機構そのものではありません。Bash とその子プロセスに、OS レベルのファイルシステムとネットワーク制限を適用します。macOS・Linux・WSL2 が対象で、ネイティブ Windows は未対応です。既定の読取範囲、書込許可、追加ディレクトリ、許可ドメイン、サンドボックス外の再試行可否を、利用時の設定で確認します。

🪝 Hooks はイベントと設定範囲を確認

Claude Code は Hooks で所定のイベントに処理を追加できます。ただし、Hooks は Claude Code 固有の唯一の制御方式ではありません。たとえば GitHub Copilot も Copilot CLI と Cloud Agent で Hooks を提供し、preToolUse で allow / deny / ask の実行判断を返せます。どのイベントが実行されるか、設定がリポジトリ・個人・管理ポリシーのどこに適用されるか、失敗時に止まるかは製品と実行環境ごとに確認します。

📝 モデルと製品機能を分ける

モデルの能力、公称ベンチマーク、クライアントの操作性、拡張機構は別の主張です。モデルを選べる製品を単一モデルで評価せず、モデル名・版・プラン・評価ハーネス・実行設定を併記できる場合だけ比較します。

🔎 導入時の確認手順

導入前に、使用する OS、クライアント、プラン、組織ポリシーを決め、同じ組合せの公式仕様を確認します。承認を有効にしても OS レベルの隔離を自動的に意味するわけではなく、隔離を有効にしても対象外のツールやサンドボックス外実行がないかを確認します。
