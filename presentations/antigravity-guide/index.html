WHAT YOU'LL ACHIEVE

各章で何ができるようになるか

12章すべてを終えると、Antigravityを安全かつ効率的に運用するプロ環境が完成します

章 やること 完了後にできるようになること フェーズ
1. Getting Started インストール・サインイン・セットアップウィザード Antigravityが起動し、安全なモードでAIに指示を出せる 導入
2. 構成設計 GEMINI.md・AGENTS.md・.agent/ の設計 AIがプロジェクトのルールを理解し、規約に沿ったコードを生成する 導入
3. Editor & Manager 2つのビューの使い分け習得 コード編集とエージェント管理を画面切替で効率的に行える 導入
4. Agent Skills SKILL.mdの作成・スコープ設計 繰り返しタスク（デプロイ・テスト等）を一言で呼び出せる 構築
5. MCP連携 DB・クラウド・外部ツールとの接続 AIがDBスキーマや公式ドキュメントを直接参照してコードを生成する 構築
6. 並列エージェント Agent Managerで複数タスクを同時実行 フロント・バック・テストを同時並行で開発し、開発速度が2〜5倍になる 構築
7. モデル選択・設定 Gemini/Claude/GPT-OSSの使い分けと承認ポリシー タスクに最適なモデルを選び、コストと品質を最適化できる 最適化
8. ワークフロー Planning/Fast Mode・カスタムWorkflow作成 日常開発パターンが型化され、チームで再利用できる 最適化
9. よくある落とし穴 レート制限・料金・自動実行リスクの把握 クォータ枯渇やアカウントBANなどの事故を未然に防げる 防御
10. プロ環境構築 サンドボックス・セキュリティポリシー設計 本番環境でも安全にAIエージェントを運用できる 防御
11. 上級テクニック ショートカット・Supercomplete・マルチモデル戦略 操作速度が倍増し、AIとの協働が「息をするように」自然になる 最適化
12. その他業務 ドキュメント・データ分析・Browser Agent活用 コーディング以外の業務もAIに委任し、「万能アシスタント」化できる 最適化

LEARNING PATH

おすすめ学習パス

目的とレベルに合わせて最適なルートを選択

Route 1: 初心者（1時間で基本習得）
最短実戦投入ルート
Getting Started → 構成設計 → 落とし穴

Antigravity初心者が最短で実戦投入するためのルート。インストールからGEMINI.md設計、よくある失敗パターンの回避まで一気に学びます。

Route 2: 中級者（半日で本格活用）
本格機能マスタールート
全ルート1 + Editor & Manager → Agent Skills → MCP → 並列エージェント → Workflows

2つのビューの使い分けからAgent Skills、MCP連携、並列エージェント運用まで幅広くカバー。

Route 3: 上級者（1日でプロ環境構築）
生産性10倍環境構築ルート
全ルート2 + モデル選択・プロ環境・上級テクニック

マルチモデル運用からサンドボックス設計、キーボードショートカットまで完全網羅。プロ環境を1日で構築します。
