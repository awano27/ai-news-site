LEARNING PATH

おすすめ学習パス

目的とレベルに合わせて最適なルートを選択

Route 1: 初心者（1時間で基本習得）
最短実戦投入ルート
Getting Started → 構成設計 → 落とし穴

Claude Code初心者が最短で実戦投入するためのルート。インストールからCLAUDE.md設計、よくある失敗パターンの回避まで一気に学びます。

Route 2: 中級者（半日で本格活用）
本格機能マスタールート
全ルート1 + 判断フレームワーク → MCP → Plugins & Skills → Workflows

拡張メカニズムの使い分けからMCP連携、プラグイン・スキル設計、並列セッション運用まで幅広くカバー。

Route 3: 上級者（1日でプロ環境構築）
生産性10倍環境構築ルート
全ルート2 + リソース集 で完全環境構築

実績あるGitHubプロジェクトの導入からAgent Teams運用まで完全網羅。プロ環境を1日で構築します。
