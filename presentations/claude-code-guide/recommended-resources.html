1日で劇的変化する導入手順

以下の7ステップを順に実行するだけで、Claude Codeの生産性が劇的に向上します。

  1. shanraisshanでベースを構築
    CLAUDE.mdテンプレートとHooks/Skills/Agentsの完全セットを自分のプロジェクトにコピーします。
    git clone https://github.com/shanraisshan/claude-code-best-practice cp -r claude-code-best-practice/.claude/ your-project/.claude/ # CLAUDE.mdを自分のプロジェクトに合わせてカスタマイズ
  2. dxプラグインでDX強化
    ステータスバーでトークン使用量・Git状態・モデル情報が常時表示されるようになります。
    claude plugin marketplace add ykdojo/claude-code-tips claude plugin install dx@ykdojo
  3. superpowers or pro-workflowを追加
    TDD/サブエージェント/レビューの自動化、または自己修正ループ/SQLite学習の仕組みを導入します。
    # superpowers（TDD/サブエージェント/レビュー） claude plugin marketplace add obra/superpowers # または pro-workflow（自己修正ループ/SQLite学習） claude plugin marketplace add rohitg00/pro-workflow
  4. Skill Creatorでプロジェクト固有Skills作成
    最初は1-2個のコアなSkillから始めましょう。
    Claudeに依頼: 「このプロジェクトのAPI設計SkillとテストSkillを作成して」
  5. gstack（必要なら）で役割分業
    15 Skillsで仮想エンジニアチーム化。大規模プロジェクトでの並行開発に威力を発揮します。
    git clone https://github.com/garrytan/gstack
  6. 小タスクで全機能テスト
    Explore → Plan → Implement → Verifyのサイクルが正常に動くか確認。lessons.mdを更新します。
    claude > Hello Worldを出力するPythonファイルを作成して
  7. 並列セッション活用（上級者向け）
    git worktreeとhandoffで並行開発。コンテキスト汚染ゼロ。
    # ターミナルを2つ開いて # Terminal 1: feature-A を開発 cd feature-a && claude # Terminal 2: feature-B を開発 cd feature-b && claude
📝 Note

最初は1-2時間でMVP構築。完璧を目指さず、使いながら少しずつ拡張していくのが成功パターンです。

最初に作るべきSkills 5選

Claude Codeの効果を最大化するために、プロジェクト初期段階で作成すべき5つのSkillsです。

1. Self-Improvement

タスク完了後に気づきをlessons.mdに記録し、CLAUDE.mdを改善するスキル。使うほどClaude Codeが賢くなる「複利成長」の仕組みを実現します。

2. Verify

実装後に自動でテスト実行・型チェック・lintを実行するスキル。コードの品質を自動的に担保し、手戻りを最小化します。

3. Safety Guard

危険な操作（本番DB・force push等）を検知して警告するスキル。本番環境を守るための最後の砦として機能します。

4. Library Reference

プロジェクトで使用するライブラリの最新ドキュメントを参照するスキル。古い情報に基づくコード生成を防ぎます。

5. Frontend Design

UI/UXのベストプラクティスに基づいてフロントエンドを設計するスキル。デザインの一貫性とアクセシビリティを自動的に確保します。

✅ Tip

Skill Creatorに「Self-Improvementスキルを作って」と頼むだけで、基本的なSKILL.mdが自動生成されます。それをカスタマイズして使いましょう。
