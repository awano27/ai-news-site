Getting Started

GitHub Copilotのプラン選定からVS Code/CLIセットアップ、Coding Agentの有効化まで。このページを読めば、すべてのCopilot機能を使い始める準備が整います。

GitHub Copilotとは

GitHub CopilotはGitHub/Microsoftが提供するAIコーディングプラットフォームです。単なるコード補完ツールではなく、開発ワークフロー全体をカバーする6つの製品群で構成されています。

  • Inline Completions — エディタ内でのリアルタイムコード補完。タブキーで候補を受け入れます。
  • Copilot Chat — サイドパネルでの対話型コーディング支援。質問応答、コード説明、リファクタリング提案。
  • Agent Mode — VS Code内の自律型エージェント。ファイル編集、ターミナルコマンド実行、エラー自動修正を行います。
  • Coding Agent (Cloud) — GitHub Actions環境で動作するクラウドベースエージェント。Issueから自動でPRを作成します。
  • Copilot CLI — ターミナルネイティブのエージェントコーディングツール。バックグラウンド実行も可能です。
  • Copilot Spaces — コードベースの知識をチームで共有するナレッジハブ。
📝 Note

利用可能な複数のAIモデルから選択可能。モデルの種類や提供状況は変わるため、最新の利用可能モデルは公式Docsを参照してください。Pro+は利用可能な全モデルへのアクセスを含みます。

プラン比較

GitHub Copilotには個人向け3プランと組織向け2プランがあります。用途に応じて適切なプランを選択してください。

プラン 価格 コード補完 Premiumリクエスト 主な特徴
Free $0 2,000回/月 50回/月 基本モデルのみ、Agent Mode利用可
Pro $10/月 無制限 300回/月 Coding Agent利用可、追加モデル
Pro+ $39/月 無制限 1,500回/月 全モデルアクセス、Claude Opus 4.6対応
Business $19/ユーザー/月 無制限 300回/ユーザー/月 組織管理、ポリシー制御、IP補償
Enterprise $39/ユーザー/月 無制限 1,500回/ユーザー/月 集中管理・ポリシー制御。より多いPremiumリクエスト枠と新機能・モデルへの早期アクセス傾向。
✅ Tip

Premiumリクエストは高性能モデルの利用に消費されます。軽量モデルは通常リクエストとしてカウントされ、Premiumを消費しません。対象モデルの最新情報は公式Docsを参照してください。

📝 Note

上限を超過した場合は1リクエストあたり$0.04の従量課金となります。高負荷なAgentを多用する場合はOrganization設定での予算制御（上限管理）が必須です。

セキュリティ・ガバナンス

データ保持ポリシー

データの保持や学習利用に関するポリシーは用途や機能によって異なります。最新の保持期間・条件は公式プライバシーポリシーおよびCopilot Trust Centerを参照してください。

【管理者向け】必須セキュリティ設定

GitHub.comの組織ポリシー設定（Settings > Copilot > Policies）で以下を設定してください。

  1. 公開コード一致（Suggestions matching public code）
    ライセンス侵害リスク防止のため Block に設定します。
  2. データ収集（Product improvements）
    機密情報保護のため OFF（無効化）に設定します。
⚠️ Warning

Enterpriseプランを使用していても、これらの設定を明示的に行わない限りデフォルトのままです。導入時に必ず確認してください。

VS Codeセットアップ

VS CodeでGitHub Copilotを使い始める手順です。

  1. 拡張機能のインストール
    VS Codeの拡張機能マーケットプレイスで「GitHub Copilot」を検索し、インストールします。Copilot Chat拡張も同時にインストールされます。
  2. GitHubアカウント認証
    VS Code右下の通知からGitHubにサインインします。ブラウザが開き、OAuthフローで認証が完了します。
  3. Agent Modeの有効化
    設定で chat.agent.enabled を有効にします。これによりCopilot Chatパネルでagentモードが選択可能になります。
settings.json
{ "github.copilot.nextEditSuggestions.enabled": true, "chat.agent.enabled": true, "github.copilot.chat.codeGeneration.useInstructionFiles": true, "github.copilot.chat.agent.autoApprove": "allow-listed", "chat.useNestedAgentsMdFiles": true, "github.copilot.enable": { "*": true } }
  • Next Edit Suggestions (NES) — 複数行にまたがる波及修正を自動提案。コード変更時に関連箇所の修正も提案されます。
  • useInstructionFiles — .github/copilot-instructions.md や .github/instructions/ のカスタム指示ファイルを自動読み込みします。
  • autoApprove — エージェントのツール使用を「許可リスト」ベースで自動承認。毎回の確認ダイアログを減らしつつ、安全性を確保。
  • useNestedAgentsMdFiles — サブディレクトリに配置したAGENTS.mdファイルもネストして読み込み。モノレポや大規模プロジェクトで必須。
📝 Note

VS Code Insiders版では最新のCopilot機能がいち早く利用できます。新機能をすぐに試したい場合はInsiders版の利用を検討してください。

CLIセットアップ

Copilot CLIはターミナルから直接Copilotのエージェント機能を利用できるツールです。

npm
npm install -g @github/copilot
Homebrew (macOS / Linux)
brew install copilot-cli
WinGet (Windows)
winget install GitHub.Copilot

プロジェクトディレクトリで copilot を起動し、CLI内で /login を実行して認証します。

✅ Tip

GitHub Codespacesには Copilot CLIがプリインストールされています。Codespacesを使えばセットアップ不要で即座に利用開始できます。

Coding Agent有効化

Coding Agent（クラウドベースの自律エージェント）を利用するには、プランと組織設定の両方の要件を満たす必要があります。

プラン要件

Coding Agentは以下のプランで利用可能です。

  • Pro — 個人利用
  • Pro+ — 個人利用（より多いPremiumリクエスト）
  • Business — 組織利用（管理者によるポリシー有効化が必要）
  • Enterprise — エンタープライズ利用（管理者によるポリシー有効化が必要）
⚠️ Warning

Copilot Business / Enterpriseでは、Coding Agentは既定で無効です。管理者がOrganization設定で有効化する必要があります。また、managed user accountsが所有するリポジトリでは利用できません。

管理者によるポリシー有効化（Business/Enterprise）

組織の管理者がGitHub.com上でCoding Agentポリシーを有効にする必要があります。

  1. Organization Settings
    GitHub.com → Organization → Settings → Copilot → Policies に移動します。
  2. Coding Agent を Enabled に設定
    「Copilot coding agent」のトグルをオンにします。
  3. リポジトリ設定
    対象リポジトリの Settings → General → Features で「Copilot」が有効になっていることを確認します。GitHub Actionsも有効である必要があります。
⚠️ Warning

Coding AgentはGitHub Actionsのランナー上で動作するため、Actionsの利用料金が別途発生します。Premiumリクエストも消費されるため、使用量に注意してください。

最初のタスク

セットアップが完了したら、VS CodeのAgent Modeで簡単なタスクを実行して動作を確認しましょう。

  1. Agent Modeを起動
    VS Codeのサイドパネルでcopilot chatを開き、モード選択ドロップダウンから「Agent」を選択します。
  2. 簡単なタスクを指示
    例: 「Hello Worldを出力するPythonスクリプトを作成して、テストも書いて」と入力します。
  3. エージェントの動作を確認
    Agent Modeがファイルを作成し、必要に応じてターミナルコマンドを実行する様子を確認します。各ステップで承認を求められるので、内容を確認して許可します。
  4. 結果を検証
    生成されたファイルとテスト結果が正しいことを確認します。
✅ Tip

最初のタスクは意図的に小さくしてください。Agent Modeの動作パターン（ファイル作成 → 編集 → テスト実行 → エラー修正）を理解してから、本格的な開発タスクに進みましょう。

1時間で完成する即実行チェックリスト

  1. VS Codeで主要設定を有効化
    chat.agent.enabled + autoApprove + useInstructionFiles + nextEditSuggestions + useNestedAgentsMdFiles を有効化
  2. .github/copilot-instructions.md を作成
    技術スタック・規約・ビルドコマンドを記載
  3. AGENTS.md をプロジェクトルートに作成
    教訓・ルール蓄積の永続記憶基盤
  4. .copilotignore で機密ファイルを除外
    .env、認証情報、秘密鍵などをインデックス対象外に設定
  5. Copilot CLIインストール
    npm install -g @github/copilot → copilot 起動 → /login で認証
  6. MCPサーバー接続
    Playwright / GitHub / DB等、必要なものだけ接続
  7. 管理者設定確認
    公開コードBlock・データ収集OFFに設定
  8. 簡単なIssueでCoding Agentテスト
    @copilotアサイン → PR自動生成を確認
✅ Tip

この8ステップを順番に実行すれば、2026年最先端のAI駆動開発環境が1時間で完成します。最初から完璧を目指さず、まず1-4を30分で済ませ、残りは翌日以降に。
