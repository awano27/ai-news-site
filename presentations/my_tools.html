RESOURCE 13 / PERSONAL TOOLS

自作ツール

判断の準備、作業の振り返り、今日のタスク。
Windows での仕事を整える、3つの道具。

自分の環境に合うものを、GitHub の手順から。

コードを取得して導入する Windows 向けツールです。対象者・導入条件・データの扱いを確認してから試用してください。

どの場面を整えたいですか

届いた依頼の判断を準備するkimeru↓ PC 作業を日誌で振り返るKaizenLog↓ 今日の予定と残件を整理するdayloop↓

01 / 判断の準備

kimeru

届いた判断依頼に、
次の一手を用意する

Windows・Teams で働く PM 向け。業務イベントを整理し、判断と承認用の下書きを支援します。

対象者
判断依頼の材料と選択肢をそろえてから決めたい、PM・リーダー。
導入条件
Windows 10 / 11、Python 3.10 以上、git。Teams の読み取りには Windows の画面操作を使います。
データの扱い
判断・ログは PC に保存。相手への返信や業務操作は既定で記録のみです。自分との Teams チャットへの投稿は送信を伴います。判断モデルや文面生成 LLM の設定によって、内容を外部へ送る場合があります。

実業務での時間短縮や判断精度は、まだ測定されていません。

導入手順・コードを見る↗ GitHub / awano27/pm-decision

02 / 作業の振り返り

KaizenLog

PC 作業の記録を、
毎日の振り返りへ

ActivityWatch の記録から、Obsidian に活動日誌や日報ドラフトを作る Windows 向けツールです。

対象者
自分の PC 作業を記録し、日々の振り返りや改善の材料にしたい人。
導入条件
Windows 10 / 11、Python 3.11 以上、pipx、ActivityWatch、Obsidian ボールト。
データの扱い
集計と日誌の保存はローカルで行います。日誌生成には LLM 不要。改善提案には別途 LLM 設定を使い、その接続先によって外部送信が生じます。

前景アプリの記録を使う個人向けツールです。勤務時間・集中力・生産性の評価には使わないでください。チーム集計には未対応です。

導入手順・コードを見る↗ GitHub / awano27/KaizenLog-

03 / 1日の計画

dayloop

今日のタスクを、
計画から持ち越し整理まで

朝の計画、次に取り組む1件、夕方の残件整理をつなぐ Windows 向けツール。判断の履歴をグラフに残します。

対象者
その日の予定を決め、未完了タスクの扱いまで整理して1日を閉じたい人。
導入条件
Windows 10 / 11、Rust・Cargo。ソースからビルドして試用します。Outlook の読み取りはクラシック版が対象です。
データの扱い
台帳は PC に保存。Jev を使う場合は判断材料を外部サービスへ送ります。GitHub・Jira・Teams の取り込みは JSON 入力で、実 API 連携ではありません。

Jev の接続がなくてもタスクループは動きます。試用前に、接続先と送信設定を利用ガイドで確認してください。

導入手順・コードを見る↗ GitHub / awano27/dayloop

試す前に確認すること

  1. 導入手順と現在の状態。各 GitHub の README・利用ガイドで、対応範囲と必要な設定を確認してください。
  2. 記録する内容と送信先。業務データを扱う場合は、保存先・外部サービスへの送信・組織の利用ルールを確認してください。
  3. 手元の環境での動作。まず試用用のデータで動作を確認し、生成された下書きや提案は自分で確認してください。

紹介内容は各リポジトリの README・利用ガイドに基づきます（確認日：2026年10月7日）。本掲載作業では、各ツールの実行や業務効果の検証は行っていません。
