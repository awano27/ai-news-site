画面を行き来して入力する、経理・事務・制作の担当者へ

画面を見て操作する AI が、
さらに安く。

GPT-6.1 Terra は、画面の内容を読み、アプリを操作する仕事を重視したモデルです。請求書の転記やフォーム入力など、繰り返す仕事を任せる候補になります。標準 API の入力・キャッシュ入力・出力単価は、GPT-6.1 Sol と GPT-5.6 Terra の半分です。[1]

01

誰の、どんな課題？

「読み取って、別の画面に入れる」が重い

書類の内容は分かっているのに、入力欄を探して転記し、また元の書類に戻る。件数が増えるほど、この行き来と確認が負担になります。Terra を試す入口は、画面で正解を確認でき、繰り返し発生する作業です。

経理・事務の担当者

請求書と入力フォームを行き来する

困りごと
日付・金額・取引先を何度も読み直して入力する。
任せたい部分
項目の読み取りと入力の下準備。最後の登録前に人が確認する。

制作・資料整理の担当者

画面を追いながら細かな操作を重ねる

困りごと
編集画面や図面を確認し、同じ操作を繰り返す。
任せたい部分
画面上の対象探しや操作。仕上がりの判断は成果物を見て行う。

記事の整理 請求書・フォーム・動画編集は公式発表の例です。上の仕事の分け方は導入を考えるための提案であり、すべての業務アプリで動く保証ではありません。[1]

02

何が変わる？

回答を読むだけでなく、画面上の作業へ

文章で手順を教わる場合

AI が操作手順を説明→人が画面を探して入力→人が結果を確認

画面操作を接続した場合

AI が画面を読む→ツールで入力・クリック→画面を読み直して確認

違いは、画面の状態を次の操作に結び付けること。Terra のモデル説明は視覚的な判断、画面操作、文章作成を中心に位置付けています。[3]

今回のニュースは、画面作業を試すときの単価が下がったこと

「安いモデルだから簡単な文章だけ」とは限りません。一方で、1件に使うトークン数ややり直し回数が変われば、支払総額も変わります。

動画編集の例と、API の動画入力対応は別です

モデル仕様は画像入力に対応し、音声・動画の直接入力は非対応としています。編集ソフトを操作する例を、そのまま動画ファイルをモデルへ渡せる仕様とは読み替えません。[3]

04

仕組みと責任範囲

Terra が判断し、接続したツールが操作する

API はモデルを呼び出す窓口です。API を呼ぶだけで、使える PC と業務アプリが一式そろうわけではありません。開発側でブラウザーやデスクトップの実行環境、ログイン、操作できる範囲、画面を戻す仕組みを接続します。[4]

モデルが担う部分

画面の意味の理解、操作の選択、結果の読み取り。

導入側が整える部分

実行環境、アプリへの接続と権限、停止条件、確認の記録。

開発者向け：Terra のツール呼び出しは Responses API が必要です。ChatGPT Work／Codex の利用者は、その製品で使える接続先と組織の設定を確認します。[3][5]

05

標準 API 料金

半額なのは、標準のトークン単価

トークンは、モデルが情報を処理するときの量の単位です。下記は 100万トークンあたり・米ドルの標準 API 単価。日本語の文字数や、仕事の件数そのものではありません。[3]

入力
$1
新しく読み込む情報
キャッシュ入力
$0.05
再利用条件を満たした入力
出力
$5
モデルが生成する情報

GPT-6.1 Sol／GPT-5.6 Terra の標準単価の半分。ChatGPT の月額料金が半額になった、という意味ではありません。[1]

単価の読み方：仮の計算

入力10万 ＋ 出力2万トークンなら

$0.10 ＋ $0.10 ＝ $0.20

キャッシュなし・標準料金で、出力側の課金対象が合計2万トークンだった場合。1件でこれだけ使うという実測ではありません。ツールや実行環境などの費用は含みません。

仕事全体の費用を数える

トークン量、再試行、ツール・実行環境、最後に人が直す時間まで含めて比較します。全タスクの総額が半分になる保証はありません。

標準料金がそのまま当てはまらない条件

仕様上、入力が272,000トークンを超えるリクエストでは、全体に入力・キャッシュ料金2倍、出力1.5倍が適用されます。キャッシュへの書き込みも別料金（100万トークンあたり30分保持 $1.25、12時間保持 $2.50）。Fast、Batch／Flex、地域処理などにも別条件があります。見積もり時はモデル仕様の最新表示を確認してください。[3]

06

Sol / Astra との使い分け

まず仕事内容で選び、同じ課題で比べる

公式ガイドは3モデルを次のように位置付けています。これは用途選びの目安です。特定の仕事でどれが速く安いかは、実際の入力で確認します。[5]

モデル選ぶ場面今回の判断
GPT-6.1 Terra画面を読み、操作する仕事。文章の作成・修正。転記や画面作業を少量から試す。
GPT-6.1 Sol複雑なコードや専門業務で、能力と費用を両立したい。難しい開発・複数条件の仕事の比較候補。
GPT-6 Astra最も難しい推論・コード・専門業務。難度が高く、品質を優先する仕事の比較候補。

表は左右にスクロールできます。最後の列は公式の位置付けを基にした記事の提案です。

開発元の評価：条件付き

「Astra 並み」は、特定の試験での結果

OpenAI は、専門的な PC 作業を試す Agents’ Last Exam で、推論設定 medium の Terra が Astra と同程度と報告しています。これは開発元の評価であり、全能力が同等という意味ではありません。[1]

同じ発表は、最も複雑なコードでは Sol／Astra がよりよい選択とも明記しています。本記事ではモデルを実行した独自の性能比較は行っていません。

07

提供条件と限界

使えるプランと、任せる範囲を確かめる

公式の提供案内

ChatGPT Work / Codex

Plus・Pro・Enterprise・Edu に提供開始。利用枠をより多くのタスクに使えるという案内ですが、無制限化や月額料金の値下げではありません。[1]

開発者向け

OpenAI API

モデル名は gpt-6.1-terra。API 利用料は製品のサブスクリプションと区別します。PC 操作には実行環境との接続も必要です。[3][4]

画面を操作できても、確認が不要になるわけではありません

記事の提案 金額・送信先・登録先を確かめ、下書きまで任せる範囲から始めます。画面の変化や判断できない項目では止めるルールを決めます。

  • 自社アプリでの成功率・日本語画面での精度：本記事では未検証です。
  • 長い作業の完走率・再試行・最終的な費用：実際の作業量で測る必要があります。
  • すべてのアプリへの接続：モデルの対応と、利用製品・組織で使える接続先は別に確認します。
08

小さく試す手順

5件の下書きで、正確さと総負担を見る

記事の提案 最初は架空データまたは利用許可のある資料5件を用意し、送信・支払いを伴わない入力の下書きまで試します。

STEP 1 / 条件をそろえる

正解と停止条件を決める

日付・金額・取引先の正解を準備。「読めない欄は推測しない」「登録前に止める」と指定します。

STEP 2 / 比較する

同じ資料で記録を取る

Terra の medium を出発点に、必要なら Sol／Astra と比較。正誤、所要時間、再試行、使用量、人の修正時間を記録します。

STEP 3 / 判断する

1件あたりの負担で選ぶ

重要項目の誤りや範囲外操作があれば保留。5件でよくても本番の成功率は断定せず、種類と件数を増やして確認します。

公式ガイドも、代表的な画像・作業を同じ推論設定で比較し、品質改善が追加時間・トークンに見合うか確かめることを勧めています。[5]

見るべき数字は、「正しく終わった1件の費用と時間」

安い単価は始めやすさにつながります。採用の判断は、確認や手直しを含めて仕事が楽になるかで行います。
