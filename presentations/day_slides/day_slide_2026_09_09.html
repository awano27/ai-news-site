WHAT SHIPPED

9/8に出たのは、モデルと編集の道具立て

一次｜OpenAI公式ブログ 2026-09-08

一次は Introducing ChatGPT Images 2.5。前世代は2026年4月の Images 2.0。公式は毎週30億枚以上が ChatGPT Images と API の GPT-Image 経由で作られている、と書く。

  • APIのモデル：gpt-image-2.5-flare と gpt-image-2.5-sunburst。

02

IMAGE FIDELITY

参照写真の被写体が、次の画でも残るか

公式の品質主張｜本号での再測定ではない

公式が挙げる品質の変化は4つ。数字のベンチマーク表は発表文にない。

残す側参照と複数ターン

  • 参照写真の被写体が、別の場所・画風でも認識しやすい
  • 特徴が持ち越されやすい
  • 長い会話でも、前の修正が残りやすい
  • 編集を重ねても画質が落ちにくい、と書く

出す側光・質感・レイアウト

  • ライティングが自然、質感が濃い
  • 実在情報を含む図の内容が正確になりやすい
  • 透過背景を含む複雑なレイアウト
  • 指定した画風への追従
Images 2.5 is better at editing only what you’ve asked for, while keeping the rest of the details the same—even with more complex subjects and backgrounds.OpenAI公式ブログ・2026-09-08

「常に顔が一致する」「文字が必ず読める」とは公式も書いていない。参照維持と局所編集は、前世代からの弱点を先に潰す更新として読む。

出典：OpenAI：Introducing ChatGPT Images 2.5

03

LATENCY

「最大50%」は上限値。経路で数字が違う

公式の遅延主張｜パートナー評価は別枠

ChatGPT側の公式文は、Images 2.0 比で生成レイテンシを最大50%削減。APIの Flare は、GPT-Image-2 より高画質で遅延50%低い。同じ「50%」でも比較対象が違う。

速度の数字は出典ごとに比較対象が異なる
主張比較対象出典の位置づけ
最大50%短いImages 2.0公式ブログ。ChatGPT側の上限
遅延50%低いGPT-Image-2公式。FlareのAPI説明
2〜4倍速いGPT-Image-2Manusの評価コメント。公式の主文ではない

解像度、品質設定、参照画像の枚数で待ち時間は変わる。上限値を自分の1枚の実測とみなさない。

出典：OpenAI：Introducing ChatGPT Images 2.5

速さの意味

速くなる利点は、1枚目の完成度よりコメント編集を何周も回せること。待ち時間が短いほど、局所編集の価値が出る。

04

PRECISION EDITING

文章で全部言い直す前に、箇所へコメントする

公式機能＋実機記事｜UIの細部は公式発表にない

公式の新機能は、画像上にコメントを置き、変えたい場所だけ指示できること。全体プロンプトを組み直して再生成するより、変更範囲が狭い。

複数ターンでは、前の修正を残したまま次の指示を積む、と公式は書く。商品はそのまま背景だけ、人物はそのまま文字だけ、が想定作業。

You can also now place comments directly on images for more focused editing.OpenAI公式ブログ・2026-09-08

TechRadarの実機記事は、編集ツールバーに Comment / Erase / Remove BG / Resize / Markup があると報告する。編集結果は別バージョンとして残る、とも書く。一部UIは8月頃から静かに入っていた、という記述もある。これは公式発表の主文ではない。

出典：OpenAI：Introducing ChatGPT Images 2.5 ／ TechRadar：Images 2.5実機（9/8付）

自分の画面にコメント編集が出ているか。公式は全プランへ展開と書くが、個別アカウントへの到着完了は確認していない。

05

SKETCH AND TEMPLATES

言葉より先に、下絵と型を渡す

公式機能｜@Sketch / Poster / Merch / プロンプト共有

SKETCH描いてから生成する

チャットで @Sketch と入れると描画画面が開く。部屋の配置、服の輪郭、雑な落書きを下絵にして完成画像へ渡す。画風と細部は文章で足す。

TEMPLATES型から始める

「Poster」「Merch」など、チラシや商品写真向けの起点。伝えたい情報、要素、画風を足す。白紙のプロンプトより型が先。

生成に使ったプロンプトを画像と一緒に共有できる。相手は同じ型を、自分の写真と文言に差し替えてやり直す。社内で「この構図で別商品」と回す用途。

出典：OpenAI：Introducing ChatGPT Images 2.5 ／ OpenAI Developer Community

SAFETY

出所表示は従来どおり。C2PAと不可視透かし

公式の安全説明｜システムカードあり

プロンプトと生成画像の検査に加え、C2PAメタデータと不可視の電子透かしを付け続ける、と公式は書く。生成物の出所を後から識別しやすくする仕組み。

09

FINISH ONE REAL JOB

最初の1本は、今ある写真を1箇所だけ直す

本号の実践手順｜初回検証のための提案

新規の綺麗な1枚より、既存の参照写真で「ここ以外を壊さないか」を見る。完成判定ができる仕事を一つ。

  1. 入口を選ぶ。ChatGPTで Images 2.5 が出ているか確認。APIならまず Flare。
  2. 参照を1枚渡す。人物か商品の写真。変えてよい箇所と残す箇所を先に書く。
  3. コメントで1箇所だけ直す。背景、文字、小物のいずれか一つ。全体プロンプトの組み直しは後回し。
  4. 形が言葉にならないなら Sketch。@Sketch で配置だけ描き、画風は短く足す。
  5. 仕上げが崩れる案件だけ Sunburst。単価は同じなので、差は待ち時間と編集の安定。
  6. 総量で残す。所要時間、再生成回数、残った崩れ、人が直した時間を一行で書く。

［ ］を埋めてからコピーできます。

本号は公開資料の整理。画質・速度・参照維持の独自測定ではない。日本の全アカウントへの到着完了は確認していない。
