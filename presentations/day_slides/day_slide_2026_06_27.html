01 · Common Ground

まず、似ている部分。

比較の前提として、両者の共通点は大きい。だからこそ「どちらを選ぶか」が悩ましい。土台が同じなら、決め手は思想と最新アップデートの方向性になる。

MIT・OSS

どちらもオープンソース。無料で自己ホスト可能、ソースを検査できる。

02 · OpenClaw

OpenClaw の最新 — 「paper cuts」で運用を磨く。

IDE でも CLI でもなく、Telegram/WhatsApp/Signal/Discord/Slack/Mattermost から操作する自律エージェント。直近サイクルは大型新機能より信頼性・配信・復旧・セッション安全の地道な改善が主軸。最新の安定版は 2026.6.10（2026-06-24）。

OpenClaw
最新安定版 2026.6.10 ／ 最新プレリリース 2026.6.11-beta.1（カレンダー版）
Peter Steinberger（@steipete）発・現 OpenClaw Foundation ／ MIT・TypeScript ／ BYO-LLM（Claude・GPT/Codex・DeepSeek・GLM 等）
  • ◆自動 fast モード（2026.6.10）— /fast auto で短い対話は即応、長い処理は通常モードへ自動復帰。状態を失わない。
  • ◆Telegram 配信の高品質化（2026.6.9）— リッチ HTML/Markdown・ステッカー・進捗ドラフト・表の正規化に対応。
  • ◆エージェント復旧の安定化（2026.6.9）— リトライ・履歴修復・返信整合で、中断したターンも可視の最終結果へ。
  • ◆Codex 連携強化（2026.6.9/6.10）— SecretRefs・スレッド文脈・承認ルーティング・型付き SDK ヘルパー。
  • ◆モデルルーティング/フェイルオーバー（2026.6.10-beta.2）— GLM 過負荷時のフェイルオーバー、ネイティブ推論レベル選択。
  • ◆チャネル制御・プラグイン外部化（2026.6.11-beta.1）— Slack リレー、Mattermost /oc_queue、DMごとのモデル上書き、公式プラグインの外部化。

03 · Hermes Agent

Hermes Agent v0.17.0 — 「到達範囲」を広げる。

「使うほど育つ」自己改善型のパーソナルAIエージェント。経験から再利用スキルを蒸留し、長期記憶/プロフィールを育てる学習ループが中核。最新は v0.17.0「The Reach Release」（タグ v2026.6.19、2026-06-19）で、メッセージ到達範囲の拡大が真の目玉。

Hermes Agent v0.17.0
「The Reach Release」／ タグ v2026.6.19（2026-06-19 公開）
Nous Research（リード Teknium）／ MIT・Python（pip install）／ BYO-LLM・モデル非依存 ／ TUI＋ゲートウェイ

05 · Who Should Use Which

あなたは、どっちを使う?

土台が同じなら、決め手は「何を重視するか」。代表的な5プロフィールで使い分けを示す。

→ OpenClaw
スマホ（Telegram/WhatsApp）から常時稼働のコーディング・エージェントを回したいソロ開発者・インディーハッカー

メッセージアプリ操作が一級市民で、多チャネル配信と復旧・セッション安全が磨かれている。並列実行・PRレビュー・バグ発見にも向く。

→ Hermes Agent
使うほど賢くなる「自己改善型」が欲しい／長期記憶やスキル蒸留を実験したい開発者・研究者

学習ループ・長期記憶/プロフィール育成・スキル自動キュレーションが中核設計。MCPカタログ（UE5.8等）や非同期サブエージェントで拡張も効く。

→ Hermes Agent
iMessage を含む日常のメッセンジャーから自己ホストAIに話しかけたい／Macリレー不要が条件のパワーユーザー

v0.17.0「The Reach Release」の本丸が iMessage（Photon、Macリレー/BlueBubbles 不要）＋Raft での到達範囲拡大。

→ OpenClaw
Discord/Slack/Mattermost でチーム運用し、モデルルーティング・セッション復旧・プラグイン拡張を重視するチーム

多チャネル運用（Slackリレー、Mattermost /oc_queue）、プロバイダルーティング/フェイルオーバー、公式プラグインの外部化が直近で強化。

→ Hermes Agent
cron 構文を書かずに定期実行（日次ブリーフィング等）＋長時間タスクの委譲をしたい自動化志向のユーザー

「Automation Blueprints」で cron なしのスケジュール化、delegate_task(background=true) で長時間タスクをバックグラウンドのサブエージェントに委譲できる（キュレーターの LLM コスト最適化も導入）。

安定運用なら OpenClaw、
育てる自律性なら Hermes。 OpenClaw vs Hermes Agent v0.17.0 · 2026·06·27
