⚡ 何が起きたのか？

2025年10月21日、Google Meetに「Ask Gemini」（会議中にAIに質問して要約・要点抽出）と「Take notes for me」（AIが自動で議事要約ドキュメント作成）が本格展開開始。

遅れて参加した人でも「Summary so far」でそれまでの要点を即キャッチアップ可能。Rapid Release（10/21開始）、Scheduled Release（11/3開始）で段階的に提供中。

最大の注目点： Business/EnterpriseプランにGeminiが同梱（追加費用なし）で、対象エディション内なら即利用可能に。

✨ 3つの革新的機能

💬 1. Ask Gemini（会議中のAI質問）

会議中にAIへ個別質問して要約・要点を抽出。「今の議論を3点で要約」「Aさんが予算について言ったことは？」などリアルタイムで質問可能。回答は自分だけに表示され、他の参加者には非表示。

📝 2. Take notes for me（自動議事作成）

AIが自動で議事要約ドキュメントをGoogleドキュメントに作成。主催者にメールでリンク通知し、カレンダー予定にも自動添付。発言タイムスタンプへの引用リンク付きで、詳細を即確認可能。

⏰ 3. Summary so far（遅刻時キャッチアップ）

会議に遅れて参加しても、「Summary so far」でそれまでの要点をその場で確認可能。議論の流れを一瞬で把握し、すぐに議論に参加できる革新的機能。

🎁 知ると得する3つの仕様

1. Ask Geminiの回答は"自分だけに見える"

個別の会話はユーザー専用で、他の参加者には非表示。プライバシーに配慮した設計で安心して質問可能。

2. 録画・字幕は保存されない

Ask Geminiはライブ字幕に一時的にアクセスして要約を生成するが、会議終了後は字幕データを保持しない。録画や恒久的な字幕保存は本機能では行わないセキュリティ設計。

3. 要約Docには"発言タイムスタンプへの引用リンク"

議事メモの詳細部から対応するトランスクリプト時刻へジャンプできる引用が自動付与。「誰がいつ何を言ったか」を即座に確認可能。

🧑‍💻 エンジニア向け：API活用で要約PDF自動化

Workspace APIで要約PDF自動配信ボット

会議後に生成されるGoogleドキュメントの議事要約をDrive API経由でPDF化し、Slack/ChatやDriveフォルダへ自動配信。

Node.js実装例： import { google } from 'googleapis'; async function exportNotesDocToPdf(docId) { const auth = new google.auth.GoogleAuth({ scopes: ['https://www.googleapis.com/auth/drive.readonly'] }); const drive = google.drive({ version: 'v3', auth: await auth.getClient() }); const pdf = await drive.files.export( { fileId: docId, mimeType: 'application/pdf' }, { responseType: 'arraybuffer' } ); return Buffer.from(pdf.data); // PDFバイナリ } 付加価値： • Meet REST APIのArtifacts（議事メモ/録画/字幕）連携可能 • PDF出力はDocs API不要、Drive APIだけでOK（10MB制限） • カレンダー予定からDocファイルIDを自動取得→PDF化の自動化

💼 ビジネス向け：即実装テクニック

📅 1. カレンダーで事前設定

予定 → 「ビデオ会議のオプション」 → Take notes with Geminiをオン（言語は英語設定）。会議前に設定しておくことで自動議事作成が有効に。

💬 2. 会議中にAsk Gemini活用

「今の議論を3点で要約」「Aさんが予算について言ったことは？」など、会議中にリアルタイムで質問。議論の流れを即座に整理可能。

📄 3. 会議後のPDF書き出し

自動生成Docを[ファイル] → [ダウンロード] → [PDF]で即PDF化。レビュー資料に添付し、次アクションはGmailの「Help me schedule」で関係者の空きを解析→1クリックで再会議提案。

⚠️ 利用時の注意点

現時点は英語のみ対応

Ask GeminiとTake notes for meは当面英語のみの提供。今後多言語展開予定ですが、現時点では英語設定が必要です。

対象プランの確認

Ask Gemini: Business Plus / Enterprise Standard/Plus
Take notes for me: Business Standard/Plus、Enterprise Standard/Plus、AI Pro、教育向けプラン等
個人Gmailでは現時点で利用不可。
