Compound Engineering: やるほど次が楽になるAI開発

Every社が公開したClaude Code用プラグインが開発ワークフローを根本から変える

2026年2月11日

💡

概要

AIにコードを書かせる時代、「書く速さ」ではなく「仕事の回し方」がボトルネックになった。Every社が公開したCompound Engineering Pluginは、Claude Codeに「計画→実行→レビュー→学習蓄積」のサイクルを組み込み、やればやるほど次の開発が楽になる仕組みを実現する。
"従来のエンジニアリングでは、機能を追加するたびに次の機能が難しくなる。Compound Engineeringはこれを逆転させる。各機能が次の機能を簡単にする。"
— Dan Shipper, Every社 CEO

4ステップ ワークフロー

1
/workflows:plan
計画
エージェントがコードベースのcommit履歴・構造を調査し、ベストプラクティスを踏まえた実装計画を生成。過去の学びも自動で参照。
2
/workflows:work
実行
Git worktreeで並行作業。計画に沿ってコード生成＋テスト作成。タスク追跡付き。
3
/workflows:review
レビュー
マルチエージェントがコードレビュー。マージ前に問題を検出し、品質を担保する。
4
/workflows:compound
蓄積（複利の源泉）
バグ、失敗したテスト、解決のひらめきを文書化。次のエージェントが同じ知見を使えるようになり、サイクルが回るほど開発が加速する。
🔄

Before / After

❌ Before（従来のAIコーディング）

  • 「この機能作って」→ AI生成
  • バグ → 手動で修正指示
  • 同じミスを繰り返す
  • コードが増えるほど品質低下
  • 知見は個人の頭の中

✅ After（Compound Engineering）

  • 過去の学びから計画を自動生成
  • 計画通りに実装＋テスト
  • マルチエージェントが品質担保
  • 学びを蓄積、次はもっと速い
  • 知見がチーム全体の資産に
🛠️

導入方法（1分）

# Claude Codeで実行
/plugin marketplace add https://github.com/EveryInc/compound-engineering-plugin
/plugin install compound-engineering

# Codex CLI / OpenCodeにも変換可能
bunx @every-env/compound-plugin install compound-engineering --to codex

💡 導入のポイント

  • Proプランでも使える — Agent TeamsのようにMAXプラン必須ではない
  • Codex CLI / OpenCodeにも対応 — Claude Code以外でも利用OK
  • 既存プロジェクトに後付け可能 — 新規プロジェクトを作り直す必要なし
🤔

Agent Teams との違い

🏃 Agent Teams

  • 複数AIを並列実行
  • 「人手を増やす」アプローチ
  • 速度の向上が目的
  • MAXプラン必須
  • トークン大量消費

🧠 Compound Engineering

  • 開発プロセス自体を改善
  • 「仕事の質を上げる」アプローチ
  • 品質の向上が目的
  • Proプランで使える
  • やるほど効率UP
"Compoundでプロセスを整えてからTeamsで並列化するのが最強の組み合わせ"
— 併用推奨
📌

ポイント

🎯 なぜ今注目なのか

  • 80/20の逆転: コードを書く時間は20%。計画とレビューに80%使うのが正解
  • 複利効果: バグや解決策を蓄積するほど、AIが賢くなる仕組み
  • 実績ベース: Every社が5プロダクトを1人×AI体制で本番運用中
  • 即導入可能: Claude Codeにコマンド2行で入る。Codex/OpenCodeにも対応
