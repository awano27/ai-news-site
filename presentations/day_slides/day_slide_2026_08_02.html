Gemini Spark（Pro）が日本で実務投入可能に 24/7 バックグラウンド動作の限界と、人間ハンドオフの設計点

02 · WHAT SHIPPED

Google が出したのは「新しいチャット」ではない

Gemini Spark はクラウド上でタスク・スキル・スケジュールを持ち、 ユーザー指示の下で能動的に動く 24/7 パーソナル AI エージェント。

  • 日本語展開（2026-07-16）Ultra 加入の日本語ユーザー向け順次提供
  • Pro 拡大（2026-07-29）数週間以内に Pro へ。月額 2,900 円帯
  • クラウド常時稼働PC/スマホオフでも Schedule・トリガーで継続
  • Workspace ネイティブGmail / Docs / Sheets 等 + リモートブラウザ

03 · WHY IT MATTERS

エンジニア視点の「5層のすごさ」

01常時稼働がクラウド側に移った

  • 端末オン前提のローカル常駐と競合軸が違う
  • 夜間・移動中でも Schedule が走る
  • 「朝起きたら終わっている」運用が現実化

02Workspace が実行面

  • API 連携で予測可能性が高い
  • Gmail→Sheets / Calendar が本命
  • 文体スキルの再利用

03価格帯の移動（日本）

  • 実験コストが約 1/5
  • 上位プラン障壁が低下
  • コンピュートは Pro < Ultra

04Task / Skill / Schedule

  • 運用単位が分割されている
  • Skill が手順の型になる
  • イベント駆動が可能

05Human-in-the-loop

  • 送信・課金は確認必須
  • Browser Takeover が明示
  • 監督可能な部下モデル

横断産業インパクト

  • 競争軸がエージェント単価×ハーネスへ
  • ローカル常駐との棲み分け
  • サブエージェント等ロードマップ
