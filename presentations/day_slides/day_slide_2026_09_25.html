「仕事の進化に合わせてCopilotを再構想する」と書き、人が頼るツールと、構築・カスタム・スケールに必要な次世代能力をつなぐ、と位置づける。[1]

02
HOME · CHAT + COWORK + OFFICE

Homeは起点。ChatとCoworkが一つに座り、Officeが中に入る。

会議・チャット・文書・メール・アプリ・エージェントのあいだを行き来する仕事の「方位磁針」として Home を置く、という説明だ。[1]

Chat

即時・会話。クイック質問、lookup、下書き作成、状況把握。ターンごとにループを保つ。

Cowork

委任。タスクを定義すると end-to-end で完了結果を返す。例: RFP応答、ローンチキット、顧客ブリーフィング、financial close package。

近日のルーティング

モードを選ばず、必要なことを述べると Copilot が Chat / Cowork / Code の適切な能力へ振り分ける、と記載。

Office in Copilot

Home からローンチブリーフ、予算モデル、デッキ作成、チーム共有ファイルの再開が可能。実の編集可能ドキュメント／ワークブック／プレゼンを作る。会話と並走編集し、@mention で共同編集。Copilot と Office アプリ間で同期する。[1]

Office アプリ側の強化も併記される。PowerPoint のブランド自動維持とカスタムテンプレート、Excel での変更理由の可視化とチャート推奨、Microsoft 365 横断の Skills（例: Excel の財務スキル、Word の法務スキル）。[1]

03
CODE · BUILD · MANAGED RUNTIME

Codeは、ファイルの隣に「小さな解決策」を置く。

知識労働の単位が文書・表・デッキだったところへ、誰でも作れる小規模ソリューションを第四の単位として加える、という主張だ。[1]

自然言語でアプリ、トラッカー、ダッシュボード、自動化、ワークフローを記述すると、Copilot がアプローチを選び構築する。永続デスクトップウィジェット、対話ダッシュボード、チーム共有のクラウド内部アプリなどが例示される。[1]

基盤と安全

GitHub Copilot と同じ基盤技術。サンドボックス実行。テナント内で安全にホスト可能。Microsoft IQ で業務コンテキストに接地し、plugins は自動同期。[1]

Managed Runtime

Microsoft Copilot Managed Runtime は、会社の Microsoft 365 環境内でコードを安全に動かすホスティング。IT が統治し、共有・ライブデータ接続・どこからでもアクセス。Cowork / Code / Copilot Studio 製アプリの基盤で、第三者・pro-code にも開放。いま preview。[1]

Code の可用性（一次）

Frontier へ end of the month にロールアウト、broad availability は coming weeks。Microsoft 365 Premium / Pro 向け preview は later this year。[1]

04
AUTOPILOT · FORMERLY SCOUT

Autopilotは、プロンプト待ちしないデジタル同僚だ。

以前は Scout と呼ばれていた。名前・役割・目標を与えると、チャネル監視、スレッドフォローアップ、定期作業、数日後のプロジェクト再開まで進める。[1]

寝ても動く

クラウドホストのため、睡眠中や注意が別にあるあいだも動き続ける。サプライヤーレビューのスケジュールから準備・会議・フォローアップまで自律、という例が書かれる。[1]

テナント内の身份

独自の identity / memory / computer / workspace を持ち、Microsoft IQ 上で組織の動き方を理解する。Teams / Outlook / chats / channels / documents に現れ、同僚のように @mention。権限・監査・統治付き。[1]

可用性

Autopilot は end of the month に private preview へ拡大、と明記。[1]

05
PRICING · FINOPS FOR AI

日常はUSL、エージェントはUBB。FinOpsがCodeまで届く。

ブログは、日常AIとエージェント的作業で課金モデルを分ける、と書く。価格表の具体額は本号では拾わない（一次に固定単価表なし）。

USL（日常）

クイック回答・下書き・要約・分析向けの固定コスト。Copilot in Chat と Word / Excel / PowerPoint / Outlook / Teams。モデル選択。Auto が精度・速度・コストでルーティング。[1]

UBB（エージェント）

高度モデルでの品質最大化。Cowork / Code / Autopilot、長時間エージェント、frontier models（Astra / Fable）は UBB。[1]

FinOps for AI（新機能の範囲）

Agent 365 のコスト管理が Cowork / Work IQ APIs から Code と Copilot Managed Runtime まで拡大（Copilot Studio 製エージェントは October 予定）。管理者は支出ポリシー、credit 承認フロー、モデル家族のグループ別許可を設定。エンドユーザーは Copilot 内で credit 使用量・残高・履歴を確認できる。[1]

近日予告（一次）

Today（Home 内の先行コマンドセンター）は October に private preview。@Copilot in Teams（チャネル共有コンテキスト）は月末に Teams private preview。Ignite は November 17–20（San Francisco + online）。[1]
