Google Research MLE-STAR発表

86pt

Google Researchが機械学習エージェント「MLE-STAR」を発表。Web検索→コード生成→標的的リファイン→アンサンブル自動化という段階的手法のMLエンジニアリング専用エージェント。ADK（Agent Development Kit）＋公式サンプルが公開されており、今日からPoCできる。MLE-Bench-Liteで63%メダル（36%ゴールド）の性能を記録。

Google Google Research MLE-STAR ADK エージェント 機械学習

🎯 重要ポイント

  • MLエンジニアリング専用エージェントとして特化設計
  • Web検索→コード生成→リファイン→アンサンブル自動化の段階的処理
  • MLE-Bench-Liteで63%メダル、36%ゴールドメダルの高性能
  • Agent Development Kit (ADK)で即座に利用開始可能
  • pip installでの簡単セットアップ、GitHubサンプル付き

🔧 技術的特徴

Python SDK GitHub連携 自動化処理 ベンチマーク対応

💻 実装例

# 1) ADK導入 pip install google-adk # 2) サンプル入手（MLE-STAR） git clone https://github.com/google/adk-samples cd adk-samples/python/agents/machine-learning-engineering # 3) 実行準備（APIキー設定など） # README手順に従って環境設定 # Poetry環境でも対応可能 # 4) エージェント起動 python mle_star_agent.py --task="データ分析自動化"

🚀 3ステップでMLエンジニアリング自動化開始。データ分析の初期モデル作成や検証の自動化が可能
