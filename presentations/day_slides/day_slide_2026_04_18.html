Codex CLI ➡ Desktop App：何が変わったか

❌ 従来の Codex CLI

  • ターミナルのみ、視覚的な差分確認が困難
  • シングルエージェント、タスクは逐次実行
  • 状態がセッション内限定、切断で消失
  • GitHub連携は手動コマンド、多ステップ
  • 長時間タスクはCTRL+Cで中断リスク
  • 認証情報は.envファイルで脆弱
➡

✅ 新しい Codex Desktop

  • マルチペインGUI、ハンク単位のLive Diff
  • 最大8エージェント並列、約3.5倍高速
  • Context Pinningで永続記憶、再開可能
  • PR作成・CI実行までワンクリック完結
  • クラウドバックグラウンド実行、PC閉じてもOK
  • OS標準のKeychain/Credential Manager統合

入手方法と移行ガイド

🖥️ 対応環境：
・ macOS 13+（Apple Silicon / Intel / ユニバーサルバイナリ）
・ Windows 11（x64 / ARM64、MSIインストーラー）
・ Linux（AppImage、Flatpak、ベータ提供中）
・ プラン：Plus $20/月から利用可、Pro/Business/Enterpriseで並列数・クラウド時間が拡張

⚠️ Codex CLIユーザー向け移行チェックリスト

  • codex.config.tomlは自動インポート（初回起動時）
  • 旧--auto-editフラグは廃止 → 「Auto Apply Hunks」設定に移行
  • カスタムフックは.codex/hooks/に配置（旧~/.codexrcから自動変換）
  • CLIも引き続き利用可（codexコマンド）。デスクトップと状態を共有
  • APIキーは初回起動時にOSのKeychain/Credential Managerへ移行（.env廃止推奨）
