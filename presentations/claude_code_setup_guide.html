Claude Code Build Guide

Claude Code の構築手順を
1ページでまとめる

Windows、macOS、Linux、WSL で Claude Code を立ち上げるまでの流れを、公式ドキュメントベースで整理しています。 日々の利用を始める最短手順に加えて、GitHub Actions と Vertex AI の導入入口も一緒に載せています。

確認日: 2026-03-08 推奨: Native Install 対象: 個人利用 / チーム導入 / CI

最初に確認する前提条件

  • 対応 OS は macOS 13 以降、Windows 10 1809 以降、Ubuntu 20.04 以降、Debian 10 以降、Alpine 3.19 以降です。
  • メモリは 4GB 以上、インターネット接続が必要です。
  • Windows では Git for Windows か WSL が必要です。
  • Claude Code は有料系アカウントで使います。無料の Claude.ai プランは対象外です。

結論だけ先に

2026年3月8日時点では、npm ではなく Native Install を第一候補にするのが安全です。 理由は、公式 docs で npm 方式が deprecated 扱いになっていて、native install は自動更新が有効だからです。

Windows でも PowerShell からそのまま導入できます。ただし内部では Git Bash を使うので、Git for Windows は先に入れておきます。
1

Git for Windows か WSL を先に用意する

Windows は PowerShell / CMD から Claude Code を起動できますが、内部実行には Git Bash か WSL が必要です。 セキュリティ重視なら WSL 2 の方がサンドボックス面で有利です。

Windows ネイティブ構成で Git Bash を使う場合、Claude Code が見つけられないときは CLAUDE_CODE_GIT_BASH_PATH を設定します。 
{
  "env": {
    "CLAUDE_CODE_GIT_BASH_PATH": "C:\\Program Files\\Git\\bin\\bash.exe"
  }
}
2

Native Install で Claude Code を入れる

公式の推奨経路です。自動更新が効き、Node.js 依存を避けられます。 Homebrew / WinGet も使えますが、更新は手動です。

macOS / Linux / WSL Recommended 
curl -fsSL https://claude.ai/install.sh | bash
Windows PowerShell Recommended 
irm https://claude.ai/install.ps1 | iex
Windows CMD Alternative 
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
npm インストールは互換性目的で残っていますが、公式 docs では deprecated 扱いです。新規導入では Native Install を使います。
3

導入確認をする

インストール直後は、まずバージョン確認、その後に診断コマンドを流します。 診断結果でインストール方式やパス周りの問題を先に潰せます。

Version Check Basic 
claude --version
Doctor Recommended 
claude doctor
Manual Update Optional 
claude update
4

ログインして最初のプロジェクトを開く

Claude Code は初回起動時にブラウザで認証します。プロジェクトのルートに移動してから起動するのが実務向きです。 

cd /path/to/your/project
claude

ここでブラウザ認証が走り、その後はターミナル内で対話セッションが始まります。 free プランでは Claude Code に入れないので、Pro / Max / Teams / Enterprise / Console のいずれかを使います。

5

更新ポリシーを決める

Native Install は自動更新されます。運用を安定化したいなら release channel を stable に寄せます。 Homebrew と WinGet は自動更新されないので、定期 upgrade を運用に入れます。

Stable Channel Ops 
{
  "autoUpdatesChannel": "stable"
}
Homebrew Manual 
brew upgrade claude-code
WinGet Manual 
winget upgrade Anthropic.ClaudeCode

GitHub Actions まで入れる場合

Claude Code から GitHub 連携を張る最短ルートは /install-github-app です。 これは direct Claude API ユーザー向けの quick setup で、GitHub App と必要な secret までガイドします。

  • ターミナルで claude を起動
  • /install-github-app を実行
  • repo admin 権限で GitHub App と secret を設定
  • Issue / PR で @claude を使って動作確認
manual setup では、Claude GitHub App の導入、ANTHROPIC_API_KEY secret の追加、workflow 配置が必要です。

Vertex AI を使う場合

会社の GCP 課金やデータ管理に寄せるなら Vertex AI 経由も使えます。 その場合は GCP 側で API・モデルアクセス・IAM を先に整えます。 

gcloud config set project YOUR-PROJECT-ID
gcloud services enable aiplatform.googleapis.com

export CLAUDE_CODE_USE_VERTEX=1
export CLOUD_ML_REGION=global
export ANTHROPIC_VERTEX_PROJECT_ID=YOUR-PROJECT-ID
docs では、model alias の自動追従で壊れないように、運用時は model version pinning を推奨しています。

実務での最短チェックリスト

  1. Git for Windows か WSL を入れる。
  2. Native Install で Claude Code を入れる。
  3. claude --version と claude doctor を流す。
  4. プロジェクトのルートで claude を起動して認証する。
  5. stable channel にするか、自動更新の方針を決める。
  6. 必要なら /install-github-app で GitHub Actions を追加する。
