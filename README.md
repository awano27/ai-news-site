# AI Intelligence Hub - ai-news-site

**visionhub.jp** のメインソースコードです。

毎日更新される**日本語AIニュースキュレーションサイト**を運用するためのリポジトリです。

## プロジェクト概要

- **公開サイト**: [https://visionhub.jp/](https://visionhub.jp/)
- **コンセプト**: 「今日のAIスライド」（毎日1本の日次スライドで、その日のAIの動きを一次ソースから追う）
- **更新頻度**: 毎日 07:00 JST 自動更新
- **コミット数**: 2,100+（2026年6月現在）

### 主な機能
- 毎日1枚の重要トピック**スライド**（ビジュアル解説）
- **レポート**形式での全体俯瞰
- **Daily News**（一次情報ソース一覧）
- 過去5,400件以上のニュースアーカイブ
- 重要度ランキング機能

### 技術構成
- 静的サイト（HTML + CSS + JS）
- Pythonスクリプトによる自動ニュース収集・処理
- GitHub Actions + Vercel で自動デプロイ

## 特徴
- 個人開発ながら**毎日欠かさず更新**を継続
- ビジネスパーソン・研究者・学生向けに、AI情報を整理して提供
- OpenAI Codex申請のためのメンテナンス効率化を検討中

**このプロジェクトは日本語AIコミュニティ向けの情報インフラ**として運営しています。
