## 1. AI Saas Kit JP

**ジャンル:** AI SaaS用フルスタックテンプレート ([Solomaker][1])

**何ができるか**

* Next.js + Supabase + Stripe + Resend + AI SDK（OpenAI / Claude / Gemini）まで一式入りのテンプレート
* `.env` 設定して `npm run dev` すると
  認証 / 課金 / AI連携 / メール配信まで動く構成
* 商用利用OK、日本語ドキュメントあり

**あなた向けのポイント（SRE/Backend目線）**

* SaaSの「認証・課金・AI呼び出し・メール配信」を一気に雛形化してくれるので、
  「インフラ/基盤設計をゼロから」は避けて、差別化部分に集中できる
* Supabase や Stripe をふだんのスタックにどう組み込むかのリファレンスにもなる

「AI SaaSを1〜2週間で形にして検証したい」時の土台としてかなり相性良さそうです。

## 2. 日程調整の Togello

「身の回りの調整ストレスを減らす」という意味で、仕事以外のところの生産性を上げる系ツールです。

## 3. DiaryPal

**ジャンル:** ランダム交換日記プラットフォーム ([Solomaker][3])

**何ができるか**

* 毎日、世界中の知らない誰かとランダムマッチして日記を交換
* 日記はマッチした相手とのみ共有される設計
* Next.js 製の無料 Web アプリ

**ソロ開発者的におもしろいポイント**

* 「日記アプリ」×「ランダムマッチング」という組み合わせで、
  継続動機をゲーム的に作っている
* 国際交流要素や、1日1回のライトなアウトプット習慣として使える
* プロダクトとしては B2C だけど、「毎日ちょっと書く」習慣ツールとしてはメンタルケア寄り

開発に疲れたときの「軽いアウトプットと他者視点」をもらえる道具として、ワークライフ全体を整える系のツールだと思います。

## 1. Solohit

## 2. Importion

* 定期的に見るドキュメントや記事を、手でコピペせずに DB に貯めたい時
