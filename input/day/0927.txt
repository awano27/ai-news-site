（ロールプレイ）世界的な**AIプロダクトアナリスト**として——日本の実在する**グッドデザイン賞**受賞プロダクトの監修者、という設定でお答えします。

**TL;DR**
ChatGPTの新機能「**Pulse**」は、過去のチャット・メモリ・（任意で）Gmail／Googleカレンダーをもとに、**毎朝1回**の“ビジュアルカード型”ダイジェストを**モバイルのChatGPTアプリ**で届けるプレビュー機能。現在は**Proプラン限定（iOS/Android）**で、Web/デスクトップ未対応。カードは**その日限り**で、保存や追いかけ質問で深掘りでき、**「Curate（見たいテーマ指定）」や👍/👎で翌日の精度が上がる**。将来的にはPlus→全ユーザーへ拡大予定。([OpenAI][1])

---

## 1) なにが出たのか（公式の位置づけ）

1. **製品名**：ChatGPT **Pulse**（チャットに“先回り”で話題を持ち込む新体験）。([OpenAI][1])
2. **配信形式**：**毎朝**、トピックごとの**カード**を提示（スキャン→展開→保存→追問）。その日の閲覧を前提に設計。([OpenAI][1])
3. **狙い**：受動的な“スクロール”ではなく、“必要な情報だけ受け取って仕事に戻る”設計。([OpenAI][1])

## 2) どう動くか（仕組みの要点）

1. **非同期リサーチ**：**夜間**に、あなたの**メモリ**（Saved memories/Chat履歴）と**フィードバック**を学習して翌朝に要約を作成。([OpenAI][1])
2. **情報ソース**：

   * **ChatGPTメモリ**＋**チャット履歴**（Memory要ON）。([OpenAI Help Center][2])
   * **Curate入力**（「明日はテニスのニュースに集中して」等）。([OpenAI][1])
   * **カードの操作信号**（👍/👎、詳細メニューの「Give feedback」）。([OpenAI Help Center][2])
   * **コネクタ**（任意）：**Gmail**／**Googleカレンダー**を**“Allow proactive activity”**で許可した場合のみ、背景で参照して示唆を生成（デフォルトOFF）。([OpenAI Help Center][2])
   * **News & trends**（関連トピックの発見性も考慮）。([OpenAI Help Center][2])
3. **締切の目安**：**Curateは“22:00（ローカル）まで”**に入れると翌朝に反映を目指す（変動あり）。([OpenAI Help Center][2])

## 3) どこで使えるか（提供状況）

1. **対象プラン**：**ChatGPT Pro**限定のプレビュー（将来はPlus→最終的に広く提供予定）。([OpenAI][1])
2. **対応デバイス**：**iOS/Androidアプリのみ**（**Web/デスクトップは未対応**）。([OpenAI Help Center][2])
3. **プラン参考価格**：Proは**$200/月**（公式Pricing）。([ChatGPT][3])

## 4) セキュリティ／プライバシー（公式記載）

1. **コネクタの学習利用**：**Gmail/Calendarの内容は学習に使われない**。いつでも切断可。([OpenAI Help Center][2])
2. **学習同意**：「**Improve the model for everyone**」を**ON**にしている場合に限り、Pulseから**会話履歴に入ったやり取り**が改善に利用され得る。([OpenAI Help Center][2])
3. **カードの寿命**：Pulseのカード自体は**当日限り**。ただし**保存**や**追問**したものは**会話履歴**として残り、通常の方法で削除可能。([OpenAI][1])
4. **表示制御**：設定で**Pulse自体のOFF**や**新規チャット画面からの非表示**が可能。([OpenAI Help Center][2])
5. **安全対策**：表示前に**ポリシー準拠の安全チェック**を実施。([OpenAI][1])

## 5) ビジネスパーソン向けの“使われ方”イメージ（例）

1. **会議前の要点カード**：その日の会議予定をもとに、**アジェンダ素案・関連資料の要点**を提示（Calendar接続時）。([OpenAI][1])
2. **出張・移動の直前確認**：フライト/ホテル/現地レストラン候補や**移動の注意点**をワンカードで提示（Gmail旅程の認識は任意の許可時）。([OpenAI][1])
3. **継続タスクの“次の一手”**：前日の議論を踏まえた**実行可能な次アクション**（例：ドラフトの叩き台、レビュー観点リスト）。([OpenAI][1])
4. **インサイトの継続フォロー**：継続的に追っている市場・製品・技術トピックの**フォローアップ**（Curateでテーマ指定）。([OpenAI][1])
5. **ワークライフの軽量支援**：**誕生日ギフトのリマインド**や**夕食の簡単レシピ**など、負担を減らす小さな提案。([OpenAI][1])

> 例：
> 「明日は**生成AI採用の国内ニュース要約**と、**来週の顧客A社向け提案の叩き台**を中心に」→ Curateで指定（～22:00）。翌朝、**2枚のカード**（ニュース要約／提案骨子）＋関連ドキュメントの確認ポイントが届く。([OpenAI Help Center][2])

## 6) 制限・既知の注意点

1. **プレビュー品質**：**外す提案**もあり得る（完了済み案件のTipsが出る等）。都度の指示・👍/👎で調整。([OpenAI][1])
2. **対応範囲**：現時点は**Pro×モバイル限定**。**Plus/Free**や**Web/デスクトップ**は今後の拡大見込み。([OpenAI][1])
3. **依存条件**：**Memoryが必須**。OFFにするとPulseも機能しない（設定で切替可能）。([OpenAI Help Center][2])

## 7) ロードマップ（公表情報）

1. **提供拡大**：**Pro → Plus → 全ユーザー**へ段階的拡大の方針。([OpenAI][1])
2. **連携強化**：今後、**利用アプリの追加連携**や、**一日の“適切な瞬間”に出す配信最適化**を検討中。([OpenAI][1])

## 8) 最低限の導入要件（事実の整理）

1. **プラン**：ChatGPT **Pro**（$200/月）。([ChatGPT][3])
2. **環境**：**iOS/Android**のChatGPT公式アプリ。([OpenAI Help Center][2])
3. **設定の前提**：**Memory ON**、（必要に応じて）**Gmail/Calendarコネクタで“Allow proactive activity”を許可**。([OpenAI Help Center][2])
