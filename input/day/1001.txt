1. 何が「新しく」なったのか（直近の変更点）

Browser（Computer Use）機能の早期プレビュー

Cursorが公式に「ブラウザを制御できる（スクショ取得・UI改善・クライアントデバッグ）」と発表。現時点ではEarly Accessチャネルでの提供で、対応モデルとしてSonnet 4.5が案内されています。
Cursor - Community Forum

UI上の呼び出し点

Chatに**“Browser”ボタンが追加（ベータ版で確認報告）。また、@（Add context）メニュー**からもBrowserを追加可能とのユーザー報告があります。
Cursor - Community Forum

要件

Google Chromeが必須（未インストール時にエラー）。WSL2ではヘッド付きモードにXサーバが必要など、環境依存の注意点が報告されています。
Cursor - Community Forum

注：公式の恒久ドキュメントや安定版のChangelogにはまだ詳細が少なく、早期プレビュー段階の機能です（Changelogは最近も頻繁に更新されていますが、この件はForum/告知ベースの情報が中心）。
Cursor
+1

2. 仕組み（公開情報ベース）

CursorのAgentがローカルChromeを操作する形で、ページ操作やスクリーンショット取得を行います（Chrome必須の挙動から推測／Forum報告で裏付け）。現状は公式実装詳細は未公開ですが、一般的にはChrome DevTools Protocol等を介した自動化が想定されます。
Cursor - Community Forum

なお、より高度な自動化・計測が必要な場合は、Cursorがサポートする**MCP（Model Context Protocol）**でPlaywright/PuppeteerやBrowser-Toolsを追加する設計が標準です。
Cursor

3. 有効化手順（Early Access）

Early Accessに切替

Settings → Beta → Update Access を Early Access に変更。
Cursor

Browser（ベータ）を有効化

Settings 内の Beta/Features セクションにある Browser をオン（Forumで案内されている導線）。
Cursor - Community Forum

Chatでの利用

Chat入力欄のツールトレイ／@メニューで Browser を追加。「このURLを開いて→要素を操作→スクショ取得→結果要約」といった指示が可能（リンクオープン等の挙動は早期段階で不安定な報告あり）。
Cursor - Community Forum

5. 実運用での拡張：MCPサーバ連携（推奨）

Playwright MCP（Microsoft公式）

Settings → MCP → Add new MCP Server で npx @playwright/mcp@latest を追加。クロスブラウザ自動化やテストが安定。
GitHub

Puppeteer MCP

Puppeteerベースの自動化。各種MCPディレクトリや実装が公開。
cursor.directory
+1

Browser-Tools MCP（AgentDeskAI）

拡張＋ローカルサーバ＋MCPサーバ構成。**コンソール／ネットワークログ収集、スクショ、Lighthouse監査（SEO/性能/アクセシビリティ/Best Practices）**などをCursorから実行可能。クッキーや機微ヘッダの除去も実装。

セットアップ例：

Chrome拡張を導入 → npx @agentdeskai/browser-tools-server@latest を起動 → npx @agentdeskai/browser-tools-mcp@latest をCursorに登録。
GitHub

6. 検証レシピ（最小構成の例）

環境準備：Early AccessでBrowserを有効化、Google Chromeをインストール。
Cursor
+1

Chatで実行：

プロンプト例：

ブラウザを有効化して次を行ってください：
1) https://example.com を開く
2) ページの <h1> テキストを抽出
3) スクリーンショットを1枚撮って添付

期待値：Agentの出力にスクショと抽出テキスト、要約が含まれる。

失敗時の切り分け：

「Chrome Required」表示→Chromeのインストール／パス設定（CHROME_EXECUTABLE）を再確認。WSL2の場合はXサーバ有無やAgent Windowの利用を検討。

補足（エンジニア向け最短レシピ：MCP追加の最小例）

Playwright MCPを追加（プロジェクト共通にしたい場合はグローバル設定）

Settings → MCP → Add new MCP Server
Type: command
Command: npx @playwright/mcp@latest


利点：安定したブラウザ操作、CI/E2E連携のしやすさ。
GitHub

Browser-Tools MCPを追加（監査・ログ収集を含む）

1) Chrome拡張を導入
2) ターミナルで: npx @agentdeskai/browser-tools-server@latest
3) Settings → MCP → Add new MCP Server
   Command: npx @agentdeskai/browser-tools-mcp@latest


利点：Lighthouse監査、ネットワーク/コンソールログの収集、スクショの自動貼付など。
GitHub
