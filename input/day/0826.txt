## 2) KPIで評価（“明日から使えるか”を厳しめ判定）

### A. エンジニア即日ツール性：**高**

* **API/SDKが即日**：公式ドキュメントに**Python／JS／Go／REST**の最小コードあり。**モデル名**は`gemini-2.5-flash-image-preview`。([Google AI for Developers][9])
* **価格の見通しが良い**：**\$0.039/枚**で**小規模PoC→本番**へ段階導入しやすい。([Google AI for Developers][2])
* **MLOps/企業導入**：**Vertex AI**で提供（組織の権限・請求・監査と合わせやすい）。([Google Developers Blog][1])
* **選択肢の冗長化**：**OpenRouter／fal.ai**経由の実行経路も用意。SaaS連携やLLMゲートウェイに組込みやすい。([OpenRouter][6], [Fal.ai][7])
* **責任ある利用**：**SynthID透かし**が標準で付与され、**検出ポータル**（SynthID Detector）も公開済み。([Google Developers Blog][1]) ([Google DeepMind][10])

**（例）最小コード：Python／画像編集**

```python
# pip install google-genai pillow
from google import genai
from PIL import Image
from io import BytesIO

client = genai.Client()  # 環境変数 GOOGLE_API_KEY を使用
prompt = "背景を夜景に差し替え、被写体の顔の特徴は維持して"

src = Image.open("input.jpg")
resp = client.models.generate_content(
    model="gemini-2.5-flash-image-preview",
    contents=[prompt, src],
)
for part in resp.candidates[0].content.parts:
    if getattr(part, "inline_data", None):
        Image.open(BytesIO(part.inline_data.data)).save("output.jpg")
```

（公式ドキュメントの手順／モデル名に準拠）([Google AI for Developers][9])

**クイック検証 3ステップ**

1. `pip install google-genai pillow` → 2) `GOOGLE_API_KEY`を設定 → 3) 上記スクリプトを実行し`output.jpg`を確認。必要なら**SynthID Detector**で透かし検出。([Google AI for Developers][9], [Google DeepMind][10])
