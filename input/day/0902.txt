4. **エンジニアが“今すぐ”試す手順（5分〜15分）**  
- 手順（番号つき、コマンド/コードは```ブロック```）  
  1. リポジトリをクローン:  
     ```bash  
     git clone https://github.com/OpenBMB/MiniCPM-V.git  
     cd MiniCPM-V  
     ```  
  2. 依存インストール:  
     ```bash  
     pip install -r requirements.txt  
     ```  
  3. モデルロードとチャット例（単一画像の場合）:  
     ```python  
     from transformers import AutoModel, AutoTokenizer  
     model = AutoModel.from_pretrained('openbmb/MiniCPM-V-4_5', trust_remote_code=True, attn_implementation='sdpa', torch_dtype='bfloat16')  
     tokenizer = AutoTokenizer.from_pretrained('openbmb/MiniCPM-V-4_5', trust_remote_code=True)  
     image = Image.open('example.jpg').convert('RGB')  
     msgs = [{'role': 'user', 'content': '画像を説明して'}]  
     res, context, _ = model.chat(image=image, msgs=msgs, tokenizer=tokenizer)  
     print(res)  
     ```  
  4. iOSアプリでモバイルテスト: https://github.com/tc-mb/MiniCPM-o-demo-iOS をビルド。  
  5. ビデオ理解テスト: 同様にvideo_pathを指定。  
- 料金/レート制限/リージョン/前提条件  
  無料（オープンソース）。レート制限なし。日本から利用可。前提: Python 3.8+, torch 2.0+, GPU推奨（CPUでも可、iPad M4で16-18トークン/s）。商用利用は登録フォーム必要: https://modelbest.feishu.cn/share/base/form/shrcnpV5ZT9EJ6xYjh3Kx0J6v8g。
