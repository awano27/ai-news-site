## 1) 何が起きたか（一次情報の要点）

1. **新モデル発表**：DeepMindが**AlphaEarth Foundations（AEF）**を公開。地球観測データを統合し“仮想衛星”のように**地球全体を高精度に表現する埋め込み**を生成。発表日は**2025-07-30**。([Google DeepMind][1])
2. **すぐ使える導線**：**Google Earth Engineのデータカタログ**に、AEFで生成した\*\*“Satellite Embedding”**を公開。**データID: `GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL`、10m解像度、64次元、2017年以降の年次**で**即日利用可\*\*。([Google for Developers][3], [Medium][2])
3. **技術裏付け**：AEFの\*\*論文（arXiv 2025-07-29）\*\*が同時期公開。\*\*年次埋め込みの提供と実務タスク（分類・変化検出・類似探索）\*\*への有効性を記述。([arXiv][5])
4. **Xの一次波及**：**Demis Hassabis／Google DeepMind／Google Earth**など**公式アカウントが一斉ポスト**。当日中に\*\*“地球を前例ない精度でマッピング”\*\*と明言。([X (formerly Twitter)][4])
5. **第三者報道**：**WIRED**などが**気候・環境監視や政策決定**への即効性を解説（**個人データを扱わない**点も明記）。([WIRED][6])

## 2) KPIで評価（“明日から使えるか”を厳しめ判定）

### A. エンジニア即日ツール性：**高**

* **Earth Engineで即座に呼べる**：`GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL` を**ImageCollectionとして読み込み**、**類似検索・変化検出・分類**を**コード数十行**で実装可能。**前処理（雲マスク等）不要の“分析用に整備済み（analysis-ready）”**。([Google for Developers][3], [Medium][2])
* **チュートリアル完備**：\*\*Similarity Search／Change Detection／分類（ee.Classifier）\*\*の手順が公式チュートリアルとして公開。**サンプルスクリプト**で即試せる。([Google for Developers][7])
* **技術信頼性**：**学術的根拠（arXiv）**と**Google公式ブログ**が同時期に整備。社内レビュー/稟議に耐える一次ソース。([arXiv][5], [Google DeepMind][1])

**最小コード（Earth Engine Code Editor / JS）**

```javascript
// Code Editor: https://code.earthengine.google.com/
var ds = ee.ImageCollection('GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL');

// 年次埋め込み（例: 2024 と 2023）を取得
var img2024 = ds.filterDate('2024-01-01','2025-01-01').first();
var img2023 = ds.filterDate('2023-01-01','2024-01-01').first();

// 年間の“変化”を埋め込みの内積で簡易評価（角度が開くほど変化）
var sim = img2024.multiply(img2023).reduce(ee.Reducer.sum());

// 可視化
Map.addLayer(sim, {min:0, max:1}, '2023↔2024 similarity');
Map.setCenter(139.767, 35.681, 9); // 東京駅付近にズーム
```

（カタログ／チュートリアルの流儀に沿った最小構成）([Google for Developers][8])

### B. ビジネス明日効率化：**中〜高**

* **立地選定・災害/インフラ監視・ESGレポーティング**に直結。**森林伐採や貯水量・都市拡張の把握、再エネ適地選定**などを\*\*“少ない教師データ”で迅速に\*\*。([Medium][2], [WIRED][6])
* **意思決定の透明化**：\*\*“個人を特定しない地表特徴”\*\*に限定される旨が報じられ、**リスク説明が容易**。([WIRED][6])
* **オペレーション負荷軽減**：**前処理不要・年次整備済み**で**外注/社内GISの前段作業を短縮**。**翌日の会議に地図と数値**を持ち込める。([Medium][2])

## 3) なぜ「7/30の一番」か（編集部視点の根拠）

* \*\*“モデル発表 × データ即提供”\*\*が同日に重なり、**評価→実装→業務適用の摩擦が最小**。([Google DeepMind][1], [Google for Developers][3])
* **公式Xが強く拡散**（DeepMind/Google Earth/関係者）。**一次情報の初動確認が容易**。([X (formerly Twitter)][4])
* **政策・産業横断の波及性**（気候・防災・サプライチェーン）。**第三者報道**も広範。([WIRED][6])

## 4) すぐに使うための“最短レシピ”

1. **Earth Engine登録** → Code Editorを開く。([earthengine.google.com][9])
2. **データ読み込み**：`GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL` をImageCollectionとして追加（上記スニペット）。([Google for Developers][3])
3. **タスク別テンプレ**：
   　・**類似地検索**（ドット積）／**年次変化検出**（ベクトル角度）／**少ラベル分類**（RandomForest等）を**公式チュートリアル**で流用。([Google for Developers][7])

## 5) 留意点（リスクと対策）

* **“埋め込み”は解釈性が限定**：64次元は**学習表現**であり物理量そのものではない。**評価指標と人手検証**を併用。([Medium][2])
* **利用ポリシー**：Earth Engineは**研究は無料／商用は契約**が基本。社内コンプライアンスと\*\*利用枠（クォータ）\*\*を確認。([earthengine.google.com][9])
* **外部報道の数値**（例：誤差低減率等）は**初期値の可能性**。最終判断は**公式ドキュメント／論文**で裏取り。([arXiv][5])
