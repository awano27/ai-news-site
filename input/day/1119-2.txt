ざっくり結論から書きます。

* **Gemini CLI**

  * ツール自体はオープンソースで無料。
  * ただし「何経由で認証するか」で

    * 無料枠（個人 Google アカウント / 無料 Gemini API / Vertex Express）
    * 定額サブスク（Google AI Pro / Ultra, Gemini Code Assist Standard / Enterprise）
    * 従量課金（Gemini API / Vertex AI）
      に分かれ、**Gemini 3.0（3 Pro）を使えるのは主に「有料 API / Vertex」「Google AI Ultra」など**です。([Gemini CLI][1])

* **Antigravity**

  * いまは **パブリックプレビューで完全無料**。
  * Gemini 3 Pro の呼び出しも「**太っ腹なレート制限付きの無料枠**」として扱われ、トークン従量課金は発生しません（将来の課金モデルは未発表）。([The Verge][2])

* **その他 IDE からの利用**

  * Google 純正は

    * **Gemini Code Assist プラグイン**（VS Code / JetBrains / Android Studio 等）
    * **IDE から Gemini CLI を呼び出す統合**
      の二系統。
  * 料金はどちらも「**Gemini Code Assist / Google AI プラン / Gemini API / Vertex AI**」のどれを使うかで決まり、**IDE 単体で Gemini 3.0 追加料金が取られるケースは公開情報上はありません**。([Google Cloud][3])

以下、項目別に整理します。

## 1. Gemini CLI からの Gemini 3.0（3 Pro）利用と料金

### 1-1. 前提

* **Gemini CLI 本体**

  * GitHub 上の OSS。CLI のインストール自体は無料。([Gemini CLI][1])
* **モデル料金**は

  * 認証方法ごとの「リクエスト上限」
    と
  * バックエンドの **Gemini API / Vertex AI の従量課金**
    の組み合わせで決まります。

### 1-2. 認証方法ごとの無料枠と上限

Gemini CLI 公式ドキュメントで定義されている無料枠は次の通りです。([Gemini CLI][1])

| 認証方法                                            | 主な用途    | 料金       | 1 日あたり上限        | 1 分あたり上限     | 利用モデル               |
| ----------------------------------------------- | ------- | -------- | --------------- | ------------ | ------------------- |
| Google ログイン（Gemini Code Assist for individuals） | 個人向け    | 無料       | 1,000 リクエスト / 日 | 60 リクエスト / 分 | Gemini ファミリーから自動選択  |
| Gemini API キー（Unpaid）                           | 個人 / 検証 | 無料       | 250 リクエスト / 日   | 10 リクエスト / 分 | **Flash のみ**（高速・軽量） |
| Vertex AI Express モード                           | 検証向け    | 無料（90 日） | アカウントごとに変動      | アカウントごとに変動   | モデルとクォータはアカウント依存    |

ポイント:

* 無料の **Gemini API キー（Unpaid）では Gemini 3 Pro は使えず Flash 限定**です。([Gemini CLI][1])
* 個人 Google ログインで Gemini 3 Pro が常時使える、という扱いには現時点のドキュメント上なっていません。3 Pro は後述のとおり、限定的なロールアウトです。([Gemini CLI][4])

### 1-3. Gemini 3 Pro を CLI から使える条件

**Gemini 3 Pro on Gemini CLI** のページで、3 Pro を使えるアカウント種別が明示されています。([Gemini CLI][4])

Gemini 3 Pro が「即利用可能」なのは以下です。

* **Google AI Ultra サブスクユーザー**（個人向け。Business 版は未対応）
* **有料 Gemini API キーで Gemini 3 へのアクセス権を持つユーザー**
* **有料 Vertex AI API キーで Gemini 3 へのアクセス権を持つユーザー**

それ以外（Google AI Pro / Code Assist Standard / 個人無料版など）は **待機リストに登録して順次開放**される扱いです。([Gemini CLI][4])

CLI 内では

* 通常は **Auto routing**

  * 簡単なプロンプト → 2.5 Flash
  * 複雑なプロンプト → 3 Pro（利用可能な場合）か 2.5 Pro
* 3 Pro を強制したい場合は `/model` で Pro ルーティング

というルーティングルールになっています。([Gemini CLI][4])

### 1-4. 有料サブスク経由（定額）での利用

CLI でリクエスト数を増やしたい場合は、Gemini Code Assist / Google AI プランのライセンスを利用します。

#### a) Gemini Code Assist 個人 / Standard / Enterprise

Code Assist の価格表より。([Google Cloud][3])

| プラン             | 料金（1 ユーザーあたり） | 1 日あたり CLI リクエスト上限 | 備考                                                  |
| --------------- | ------------- | ------------------ | --------------------------------------------------- |
| Individuals     | 無料            | 1,000              | VS Code / JetBrains / Android Studio プラグイン＋CLI が利用可 |
| Standard（月払い）   | 22.80 USD / 月 | 1,500              | 年払いにすると 19 USD / 月                                  |
| Enterprise（月払い） | 54 USD / 月    | 2,000              | 年払い 45 USD / 月。エンタープライズ機能付き                         |

* Code Assist ページには、**全プランで「Gemini 3 へのアクセス」欄があり、個人版・Standard・Enterprise いずれも「Waitlist 経由、もしくはプレビュー Channel で提供」**と書かれています。料金自体は 3 Pro が入っても変わらず、**追加サーチャージは無し**という扱いです。([Google Cloud][3])
* つまり IDE も CLI も、**Code Assist のサブスク内で 3 Pro を共有**する形になります。

#### b) Google AI Pro / Ultra

* **Google AI Pro** と **Google AI Ultra** の個人プランは

  * Gemini アプリ
  * Flow / Veo など
    に加えて、Gemini CLI / Code Assist にも高い上限を付与する「上位サブスク」となっています。([Google Cloud][3])
* Gemini CLI から見たときは「Google ログインでの定額プラン」として扱われます。

Ultra ユーザーは前述の通り **Gemini 3 Pro 即時利用対象**になっているので、**CLI と IDE の両方で 3 Pro を定額枠の中で利用**できます。([Gemini CLI][4])

### 1-5. Pay-As-You-Go（API / Vertex AI）での Gemini 3.0 料金

CLI を **Gemini API キー**または **Vertex AI** で認証すると、リクエストはそのままバックエンドの課金対象になります。([Gemini CLI][1])

#### Gemini 3 Pro API 料金（2025-11-19 時点）

公式の Gemini API 料金表より。([Google AI for Developers][5])

* モデル: `gemini-3-pro-preview`
* 無料枠: **なし**（Free Tier の欄は「Not available」）
* 有料（1M トークンあたり、USD）

| コンテキスト長           | 入力トークン   | 出力トークン（thinking 含む） | コンテキストキャッシュ |
| ----------------- | -------- | ------------------- | ----------- |
| プロンプト ≤ 200k トークン | 2.00 USD | 12.00 USD           | 0.20 USD    |
| プロンプト > 200k トークン | 4.00 USD | 18.00 USD           | 0.40 USD    |

* ストレージ料金: 4.50 USD / 100 万トークン時間（キャッシュ保持時間に応じて課金）
* Medium 記事でも「**gemini-3-pro-preview 自体に Free tier は無い。AI Studio 上でのテストは実質的には開発者向け無料枠でやることになる**」と補足されています。([Medium][6])

#### Vertex AI 経由

* Vertex AI 上でも「Gemini 3 Pro は Gemini API と同じ単価でプレビュー提供」と案内されています。([Google Cloud Documentation][7])
* Express モード 90 日間は課金不要ですが、その後は通常の **Vertex Generative AI 料金表**に従います。([Gemini CLI][1])

## 2. Antigravity からの Gemini 3.0 利用と料金

### 2-1. 提供形態

* **Antigravity は Windows / macOS / Linux 向けの新 IDE**

  * 複数エージェントがエディタ・ターミナル・ブラウザを直接操作
  * 作業ログや計画を「Artifacts」としてまとめてくれるエージェントファースト設計([The Verge][2])

### 2-2. 料金

複数メディアが一致して次のように報じています。([The Verge][2])

* **Antigravity 本体**

  * 現在は **パブリックプレビューで完全無料**。
  * OS 別クライアントのダウンロードも無料。
* **Gemini 3 Pro 利用**

  * Antigravity 内から呼び出される Gemini 3 Pro も

    * 「**Generous rate limits**」
    * 「5 時間ごとにリセット」
      として扱われており、**別途トークン課金は発生しない**。
  * Google は「ごく一部のヘビーユーザーだけがこのレート制限にぶつかる」とコメントしており、通常利用ではほぼ無料で使える想定。

ただし注意点として:

* 公式に「将来も無料を保証する」とは言っていません。

  * プレビュー期間が終わると

    * Google AI Pro / Ultra への紐付け
    * Vertex AI / Gemini API キーの BYO モード
      などの課金モデルに切り替わる可能性があります。
* いまのところ **「Antigravity から Vertex / API キーを直接使って自前課金するモード」**は公開情報では見当たらず、デフォルトは「Google 側が負担する無料レート制限付き 3 Pro」の形です。([Dataconomy][8])

## 3. その他 IDE からの Gemini 3.0 利用料金

「その他 IDE」は大きく次のパターンに分かれます。

1. **Google 純正の Gemini Code Assist プラグイン**
2. **Gemini CLI を IDE から呼ぶ統合（VS Code / Zed など）**
3. **サードパーティ IDE があなたの Gemini API / Vertex を使う BYO キー方式**

### 3-1. Gemini Code Assist プラグイン（VS Code / JetBrains / Android Studio など）

Gemini Code Assist の公式ページより。([Google Cloud][3])

* 対応 IDE

  * VS Code
  * JetBrains IDE（IntelliJ / PyCharm 他）
  * Android Studio
  * Cloud Workstations など
* 料金プランと特徴

| プラン             | 料金            | IDE での利用                                          | Gemini 3 へのアクセス                                             |
| --------------- | ------------- | ------------------------------------------------- | ----------------------------------------------------------- |
| Individuals     | 0 USD / 月     | VS Code / JetBrains / Android Studio プラグインが無料で利用可 | **Waitlist 経由**で順次開放。AI Ultra ユーザーは優先。                      |
| Standard（年払い）   | 19 USD / 月    | 同上 + チーム管理、Cloud 連携                               | Gemini 3 へのアクセス欄は個人版と同じ（Waitlist / Preview Channel）。追加料金なし。 |
| Standard（月払い）   | 22.80 USD / 月 | 同上                                                | 同上                                                          |
| Enterprise（年払い） | 45 USD / 月    | 同上 + エンタープライズ機能（カスタムコードベース、IP 保護など）               | Gemini 3 は「Preview Channel で全ユーザーに提供予定」。追加料金なし。             |
| Enterprise（月払い） | 54 USD / 月    | 同上                                                | 同上                                                          |

重要な点:

* 価格表には **「Gemini 3 へのアクセス」欄があるが、どのプランも料金は変わらず**
  → Gemini 3 が IDE に入っても、**Code Assist のサブスク料金に上乗せはされません**。([Google Cloud][3])
* Code Assist のリクエスト上限は Standard / Enterprise それぞれ

  * 1,500 / 2,000 リクエスト / 日
  * 120 リクエスト / 分
    とされており、「全モデル利用可能」と明記されています。([inSite(インサイト)][9])
  * 実際には、Gemini 3 は Waitlist や Preview Channel で段階的に有効化されるイメージです。

したがって

* **VS Code や JetBrains から「Code Assist 経由で」Gemini 3 を使う場合**

  * 追加トークン課金ではなく
  * 上記サブスクリプション料金の範囲内
    で利用するイメージになります（ただし日次リクエスト上限あり）。

### 3-2. IDE から Gemini CLI を呼ぶ場合（VS Code / Zed など）

Google Developers Blog にあるとおり、VS Code などの IDE から **Gemini CLI を統合**して使うことができます。([Google Developers Blog][10])

* 料金面では

  * **IDE プラグイン自体は無料**
  * 実際のモデル利用は「Gemini CLI のクォータと課金体系」に完全に準拠

つまり

* 「VS Code + Gemini CLI」でも
* 「Zed + Gemini CLI」でも

**コストは Gemini CLI の章で述べた内容と同じ**です。

### 3-3. サードパーティ IDE で BYO Gemini API を使う場合

Cursor や各種 AI IDE の比較記事では「OpenAI や Claude を BYO API キーで使う」モデルが一般的とされていますが、現時点の公開情報では **Gemini 3 を公式に統合しているサードパーティ IDE は限定的**です。([デジタルアプライド][11])

もし今後

* 「自分の GEMINI_API_KEY を IDE に設定して使う」
  という形で Gemini 3 Pro を使う IDE が出てきた場合の料金は

1. IDE のサブスク料金
2. Gemini 3 Pro API の従量課金（前述の 2/12 USD など）

の **二重構造**になります。

現時点で公式に確認できるのは

* Google 純正の Code Assist プラグイン
* Gemini CLI 統合

のみなので、「他 IDE の Gemini 3 料金」は実質的に

> Code Assist か Gemini CLI 経由の料金体系に従う

と見なして問題ないと考えられます。

## 4. まとめと実務的な選び方

エンジニア視点で整理すると:

1. **まず雰囲気だけ掴みたい / 個人利用**

   * Gemini CLI を

     * Google 個人アカウント
     * または 無料 Gemini API キー
       で使う。
   * Gemini 3 Pro 前提なら

     * Google AI Ultra
     * もしくは有料 Gemini API キー
       が必要。

2. **IDE から本格利用したい（VS Code / JetBrains など）**

   * チーム利用なら **Gemini Code Assist Standard**
   * セキュリティやカスタムコードベースが重要なら **Enterprise**
     を選ぶと「IDE + CLI + エージェント」が全部まとまるので運用しやすいです。

3. **バックエンドのコストを厳密にコントロールしたい**

   * Gemini CLI / Antigravity は日次リクエスト単位でしか把握しづらいので
   * 解析コストが大きいワークロードは **Gemini API / Vertex AI で直に叩く**構成にして

     * 2 / 12 USD / 1M tokens（≤200k）
     * 4 / 18 USD / 1M tokens（>200k）
       を直接モニタリングするのが安全です。([Google AI for Developers][5])

もし「自社で使うとしたらどの組み合わせが一番コスパ良さそうか」を検討したければ、利用人数や想定トークン量を書いてもらえれば、ざっくり試算表を作ります。
