## 0. TL;DR

1. **Grok 4.1 Fast** は、2Mトークンコンテキストと高性能なツール呼び出しに特化した、xAIの新しいフラグシップ級エージェント向けモデルです。([xAI][1])
2. **Agent Tools API** は、Xのリアルタイムデータ・Web検索・コード実行・ファイル検索・MCP連携を、xAI側でフルマネージド提供する「エージェント用サーバサイドツール群」です。([xAI][1])
3. **コスト**は入力 0.20ドル / 100万トークン・出力 0.50ドル / 100万トークンと、GPT‑5.1・Gemini 3 Pro・Claude Sonnet 4.5 などのフラグシップモデルより数倍安く、12月3日までは OpenRouter と Agent Tools API が無料トライアル中です。([xAI][1])

## 1. プロダクト概要と「何が新しいか」

### 1-1. Grok 4.1 Fast とは

* **位置付け**

  * xAI の「実運用向けフロンティアモデル」
  * マルチモーダル (テキスト + 画像) で、**高性能なツール呼び出しと長コンテキスト推論**に最適化されたファミリー。([xAI][2])
* **主なスペック**

  * コンテキスト長: **2,000,000 トークン**([xAI][1])
  * バリアント:

    * `grok-4-1-fast-reasoning`  - 高度な推論・エージェント用途
    * `grok-4-1-fast-non-reasoning`  - レイテンシ重視の「Fast」モード([xAI][1])
* **トレーニングと品質**

  * ツール呼び出しが多用されるシミュレーション環境で RL トレーニング
  * τ²-bench Telecom や Berkeley Function Calling v4 などのエージェント系ベンチマークで高スコアを記録し、他社フラグシップ (GPT‑5, Claude Sonnet 4.5, Gemini 3 Pro など) を上回ると報告。([xAI][1])
  * Grok 4 Fast 比で**幻覚率を半減**しつつ、Grok 4 に近い推論性能を維持。([xAI][1])

### 1-2. Agent Tools API の新しさ

**大きなポイントは「X ネイティブのエージェント基盤」になったこと**です。

* **サーバサイドツールのラインナップ**([xAI][1])

  * `x_search` - X のリアルタイム投稿検索
  * `web_search` - インターネット検索
  * `code_execution` - サンドボックス上の Python 実行
  * `files / collections_search` - アップロードファイルやコレクションの検索
  * `mcp` - 外部 MCP サーバとの接続 (独自ツールや社内システム連携)

* **特徴**

  * すべて **xAI インフラ側で実行される**ため、

    * 各ツール用 API キー管理
    * レートリミット制御
    * サンドボックス構築
    * 検索パイプライン構築
      を開発側でやらなくてよい。([xAI][1])
  * Grok が自律的にツールを選択し、**複数ツールを並列・複数ターンに渡って呼び出す**エージェントとして動作。

* **X データとのネイティブ統合**

  * 内部ベンチマーク「X Browse」で、X 上のマルチホップ検索・センチメント分析・トレンド抽出の性能が、GPT‑5 や Claude Sonnet 4.5 などを上回ると公表。([xAI][1])

### 1-3. 無料トライアルと提供形態 (2025-11-22 時点)

* xAI 公式発表によると、**11/19〜12/3 までの約2週間**

  * **Grok 4.1 Fast** が OpenRouter 上で無料
  * **Agent Tools API** も xAI API 経由で無料([xAI][1])
* OpenRouter の `x-ai/grok-4-1-fast:free` エンドポイントでは、入力・出力とも **0ドル / 100万トークン** と明記。([OpenRouter][3])

## 3. 競合モデルとの違い

ここでは、主に **GPT‑5.1 (OpenAI)**、**Gemini 3 Pro (Google)**、**Claude Sonnet 4.5 (Anthropic)** との比較で整理します。

### 3-1. 機能面の差分

1. **X データへのネイティブアクセス**

   * Grok 4.1 Fast + Agent Tools:

     * `x_search` で **X のリアルタイム投稿を直接ツールとして叩ける**
     * 内部ベンチマーク「X Browse」で、X 上のマルチホップ検索・センチメント分析に特化した評価を実施。([xAI][1])
   * 競合モデル:

     * GPT‑5.1 / Gemini / Claude も Web 検索・ツール呼び出し機能を提供しているが、X とのこのレベルの**ネイティブ統合は現時点では xAI 固有**のポジショニング。

2. **フルマネージドなエージェント用ツール群**

   * Grok:

     * Web 検索・X 検索・コード実行・ファイル検索・MCP 連携などを、**xAI のインフラ側で完結**させる設計。([xAI][1])
     * ユーザーは「Grok 用のツール」を宣言するだけで、API キーやインフラ整備は不要。
   * 競合:

     * OpenAI / Google / Anthropic もツール呼び出しを提供しているが、検索・コード実行・社内データ連携などを統合するには、**開発側でのオーケストレーションや外部サービス統合が必要なケースが多い**。

3. **コンテキスト長**

   * Grok 4.1 Fast: **2M トークン**([xAI][2])
   * Gemini 3 Pro: 入力コンテキスト **1M トークン**([Google AI for Developers][4])
   * GPT‑5.1 chat-latest: コンテキスト **128k トークン** と公式ドキュメントに記載。([OpenAI Platform][5])
   * Claude Sonnet 4.5: 料金体系が「200k トークン以下 / 超」で分かれているため、少なくとも 200k トークン級の長コンテキスト。([Anthropic][6])

   → 長大なマルチドキュメントや長時間ログを**1コンテキストに押し込んでエージェントに渡したい用途では、Grok 4.1 Fast がかなり攻めたスペック**になっています。

4. **エージェント系ベンチマークでの位置付け**

   * Grok 4.1 Fast + Agent Tools は

     * τ²-bench
     * Berkeley Function Calling v4
     * Research-Eval / FRAMES / X Browse
       などのツール拡張・検索系ベンチマークで、GPT‑5.1 や Claude Sonnet 4.5、Gemini 3 Pro より高スコアかつ低コストという xAI / VentureBeat のレポート。([xAI][1])

### 3-2. 料金比較 (ざっくり)

**簡易シナリオ比較**

例として

* 出力 20万トークン
  を 1 ジョブで使うケースを想定すると:

* Grok 4.1 Fast

  * 入力: 0.20ドル
  * 出力: 0.20 × 0.5 = 0.10ドル
  * **合計: 約 0.30ドル**

* GPT‑5.1

  * 入力: 1.25ドル
  * 出力: 0.20 × 10 = 2.00ドル
  * **合計: 約 3.25ドル**

* Gemini 3 Pro

  * 入力: 2.00ドル
  * 出力: 0.20 × 12 = 2.40ドル
  * **合計: 約 4.40ドル**

* Claude Sonnet 4.5

  * 入力: 3.00ドル
  * 出力: 0.20 × 15 = 3.00ドル
  * **合計: 約 6.00ドル**

ざっくりいうと、**同じトークン量で比較した場合、Grok 4.1 Fast はフラグシップモデル群の約 1/10〜1/20 レベルのコスト**になっています
(ただしツール呼び出し料金・Live search 料金が別途乗る点に注意)。([xAI][2])
