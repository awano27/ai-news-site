生成AIの進化スピードは、毎日1時間ニュースを追っても追いつけないほど加速しています。 運営者自身が「情報を追う時間を、使う時間に変えたい」と思い、 公開情報を一次ソースから運営者が拾い、下書き段階で Claude Code の補助を受けつつ、要点整理と独自視点の加筆は運営者が担当し、 5分で読み切れる日次スライドとして配信することにしました。 読者と同じ 忙しいエンジニア・ビジネスパーソン の時間を守ることが、当サイトの使命です。

編集方針（E-E-A-T を満たすための運用ルール）

当サイトは Google 検索品質評価ガイドラインの E-E-A-T (Experience / Expertise / Authoritativeness / Trust) を運用ルールに落とし込んでいます。

1. 一次ソース主義

  • 公式発表 / 原論文 / 法定開示（SEC S-1・8-K 等） を一次ソースとして優先
  • 二次メディア（テック系ブログ等）は裏付けと時系列補完のみに利用
  • 匿名掲示板・SNS の断片情報は Rumor ラベル付きでのみ扱う

2. 事実と推測の分離

  • Fact-A/B/C：一次ソースで確認できる事実（信頼度で三段階）
  • Claim：当事者の主張（数値・性能主張を含む）
  • Opinion / Forecast：運営者の解釈・予測（主観であることを明示）

3. 時刻の明記

発表タイミングは UTC と JST の両方を併記し、タイムゾーンの取り違えによる誤報を防ぎます。

4. 日次スライドの制作プロセス

  1. Claude Code で RSS・Atom・公式ブログ・arXiv 等から新着を収集
  2. 重複除去 → カテゴリ分類（AI Model / Business / Research / Product / Hardware）
  3. スコアリング（20〜100点）で重要度順にソート
  4. 運営者が一次ソースを全件クリック確認し、誤報・釣り見出しを除外
  5. Reveal.js テンプレートに落とし、手作業でフィギュアの補強と要約リライト
  6. 公開 → GitHub Issues / お問い合わせで訂正依頼があれば24h 以内に対応
AI に書かせたものを、AI に書かせたまま公開しない。 必ず人が一次ソースを見て、文脈と数字の妥当性を確かめる。これが運営者の譲れないルールです。

訂正・削除ポリシー（Trust）

  • 誤りが判明したページは、原文を残したうえで訂正ブロックを追記します（黙って書き換えません）
  • 変更履歴は GitHub のコミットログ で誰でも追跡できます
  • 第三者からの削除・訂正依頼は お問い合わせ または GitHub Issues で受付 → 原則 3 営業日以内に一次対応
  • 名誉毀損・著作権侵害・プライバシー侵害の恐れがある内容は即時ブロックしたうえで調査します

読者からよくある質問（FAQ）

このサイトは AI が自動生成していますか？

いいえ。Claude Code が一次情報の収集・下書きを支援しますが、 公開前に運営者（人間）が全件レビューし、事実確認と読みやすさの調整を行っています。 「AI が書いたものを、AI のまま公開しない」が運営ルールです。

記事の内容を引用・転載できますか？

引用元として本サイトの URL を明記していただければ、公正な引用の範囲でご利用いただけます。 丸ごと転載は事前にご相談ください。

スライドに誤りを見つけました。どこに連絡すれば？

一番早いのは GitHub Issues、 非公開で伝えたい場合は awano27@gmail.com までご連絡ください。 原則 3 営業日以内に一次返信します。

企業から取材・広告出稿の相談はできますか？

お問い合わせページからご連絡ください。 ただし記事内容への編集的介入を伴う依頼はお受けしません。

Claude Code の導入支援はしていますか？

個別コンサルは現時点では受けていませんが、GitHub Discussions で公開質問には可能な範囲で回答しています。
