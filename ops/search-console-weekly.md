# Search Console 週次チェックリスト

毎週1回（月曜朝を推奨）、15分でPV成長の手応えを確認する運用メモ。

https://search.google.com/search-console を開き、プロパティ `visionhub.jp` で以下を順に確認。

## 1. 「概要」ダッシュボード (2分)

- [ ] 合計クリック数の前週比（右上の日付範囲を「過去7日間 vs 過去28日間」で比較）
- [ ] 合計インプレッション数の前週比
- [ ] 平均掲載順位の前週比（下がっていれば良いシグナル）

**目安:** 最初の1ヶ月はほぼゼロ、2ヶ月目で週数百インプレッション、3ヶ月目で週数千インプレッションに到達していれば健康。

## 2. 「パフォーマンス」→クエリ一覧 (5分)

- [ ] **インプレッション上位10** を見て、「想定外に上がっているキーワード」をメモ
- [ ] そのキーワードで**順位が11位〜20位（2ページ目）**の記事はチャンス → その週にブラッシュアップして1ページ目を狙う
- [ ] **CTR が極端に低い**（1% 未満）記事はタイトル・meta description の改善候補

## 3. 「ページ」タブ (3分)

- [ ] **インプレッション上位10ページ**をピックし、どのHub/digest/slideが効いているか可視化
- [ ] **「ページがインデックス登録されました」**の件数が増えているか（目標: 週+5件）
- [ ] **除外「重複ページ」**が多くないか（多ければ内部リンク/canonical 見直し）

## 4. 「インデックス作成」→ページ (3分)

- [ ] **登録済み件数の推移**（週次で増加していれば OK）
- [ ] **除外理由トップ3** を確認：
  - 「クロール済み — インデックス未登録」 → コンテンツ量・独自性を増やす
  - 「ページのインデックス登録を妨げている（noindex）」 → 誤って noindex を付けていないか
  - 「代替ページ（適切な正規タグあり）」 → 正常、無視 OK

## 5. 今週のアクションを決める (2分)

上記で見つけた改善候補から**1つだけ**選んで実施する：
- 例1: 「Claude Code 料金」で 14 位 → Hub記事の該当セクションを増強
- 例2: 「AIニュース 2026年3月」で 8 位だが CTR 2% → title を「読みたくなる形」に書き直す

## 6. メモの保存

見つけた発見を `ops/weekly-notes/YYYY-MM-DD.md` に 3 行でメモ。3 ヶ月後に振り返ると、どの改善が効いたか見える化できる。

---

## よく使う Search Console の絞り込み条件

- **検索タイプ=Web、期間=過去28日** — 大きなトレンドを見る
- **国=Japan** — 日本のユーザーだけに絞る（主要読者層）
- **デバイス=モバイル** — Discover 流入の確認に有効
- **ページ=`/presentations/hubs/`** — Hub 記事だけのパフォーマンスを見る

## 失敗のシグナル（見つけたら即対応）

- 週次でインプレッションが**2週連続で減少** → 手動ペナルティ or 大規模サイト変更を疑う
- 「ページ体験」が**赤** → Core Web Vitals の悪化 → 画像遅延やスクリプトを見直し
- 「セキュリティと手動ペナルティ」に**何か表示** → 即詳細を確認して対応
