# TOPページ リデザイン設計書

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** TOPページのコンテンツ導線を「スライド / レポート / ニュース」3カードに集約し、何が開くか一目で分かるようにする

**Architecture:** 既存index.htmlを編集。セクション削減（4→3）、ナビ簡略化（7→4項目）、CSS模擬プレビュー付き3カードをメイン導線に

**Tech Stack:** HTML/CSS（既存のインラインスタイル方式を維持）

---

## 変更概要

### ナビゲーション
- 7項目 → 4項目: スライド / レポート / ニュース / リソース
- 3カードと同じラベルで統一

### ヒーロー
- 見出し: そのまま維持
- 説明: 2行 → 1行に短縮
- CTA4ボタン: 削除（直下3カードがCTA）
- 統計: 1行に圧縮

### 3カード（新設・メイン導線）
各カード構成:
1. 形式アイコン＋ラベル（📊スライド / 📋レポート / 📰ニュース）
2. CSS模擬プレビュー（画像不要）
3. タイトル＋説明1行
4. 日付＋CTAリンク

| # | ラベル | タイトル | 説明 | リンク先 |
|---|--------|---------|------|---------|
| 1 | 📊 スライド | 今日の1枚 | 1トピックをビジュアルで深掘り | day_slides/最新 |
| 2 | 📋 レポート | 今日の全体像 | 複数ソースから自動収集した分析 | auto_daily_report.html |
| 3 | 📰 ニュース | 今日の全記事 | X/RSS/SNSの生データ一覧 | daily-news/ |

### CSS模擬プレビュー
- スライド: 暗い背景にスライド風の矩形
- レポート: セクション見出し＋箇条書き風の横線
- ニュース: カード型グリッドのミニチュア

### 削除セクション
- START HERE（SIGNAL/00, ROUTE/01〜03）→ 3カードに統合
- LATEST SIGNALS → 3カードに統合

### 維持セクション
- Resources（6リンク、そのまま）
- フッター

### モバイル対応
- 3カード → 縦積み
