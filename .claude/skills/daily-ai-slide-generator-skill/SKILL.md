# デイリーAIニューススライド生成スキル

## 概要

このスキルは、日付を指定するだけで、AIニュースのPDF資料からウェブスライドを自動生成し、GitHubページに公開するまでの全工程を自動化します。

## 使い方

### 基本コマンド

```
MMDDのスライドを作成して
```

例:
- `0105のスライドを作成して`
- `今日のスライドを生成して`
- `1月5日のAIニューススライドを作って`

### 詳細指定

```
0105のスライドを「タイトル」というタイトルで作成して
```

## 実行される処理

1. **PDF画像変換**: `input/day/MMDD-*.pdf` を高解像度JPG画像に変換
2. **HTML生成**: テーマに合わせたスライドHTMLを自動生成
3. **インデックス更新**: 日次スライド一覧ページに新エントリを追加
4. **Git操作**: コミット・プッシュして GitHub Pages に反映

## 必要なファイル

```
input/day/
  ├── MMDD.txt         # ニュース要約
  ├── MMDD.png         # トップ画像
  └── MMDD-Topic.pdf   # スライド元PDF
```

## 特徴

- **テーマ自動設定**: 内容に応じてカラースキームを自動選択
- **コンフリクト自動解決**: Git操作時のマージ競合を自動処理
- **レスポンシブデザイン**: モバイル対応の美しいスライド
- **アクセシビリティ**: ARIA属性とセマンティックHTML

## 出力例

生成されるスライド:
- URL: `https://awano27.github.io/ai-news-site/presentations/day_slides/day_slide_YYYY_MM_DD.html`
- ページ数に応じた画像スライド
- テーマカラーを適用したヘッダー・フッター
- インデックスページへの自動リンク

## トラブルシューティング

### PDFが見つからない
→ `input/day/MMDD-*.pdf` の存在を確認

### Git コンフリクト
→ 自動解決を試みますが、複雑な場合は手動マージが必要

### スライド画像が表示されない
→ PDF変換が正常に完了したか確認

## カスタマイズ

テーマカラーは自動設定されますが、手動で変更も可能:

```python
css_vars = """
:root {
  --primary: #7c3aed;    # メインカラー
  --accent: #14b8a6;     # アクセント
  --bg-light: #f5f3ff;   # 背景色（明）
  --bg-dark: #1e1b4b;    # 背景色（暗）
}
"""
```
